# 0. Status vocabulary / 状态词

- **POST-RESET CONFIRMED（重构后已确认）** — explicitly re-discussed/accepted after the Product Architecture reset.
- **LEGACY-INHERITED / REVALIDATED LATER（旧方案继承 / 后来重新验证）** — concept came from older planning but was substantively revalidated later.
- **CONFIRMED CAPABILITY / CONTAINER DEFERRED（能力已确认 / 容器延后）** — user/product need exists; exact page/module/container is not decided.
- **CONFIRMED SUBJECT / DETAILS DEFERRED（主题已确认 / 细节延后）** — domain/product subject exists, exact product model remains open.
- **LEGACY-INHERITED / SEMANTICALLY ABSORBED（旧方案继承 / 已被新语义吸收）** — old label/component is not canonical, but part of its legitimate product need survives inside a newer model.
- **LEGACY-INHERITED / REVALIDATION PENDING（旧方案继承 / 等待重新验证）** — still appears as a future subject but dedicated revalidation has not occurred.
- **LEGACY-INHERITED / EXISTENCE UNRESOLVED（旧方案继承 / 是否存在未决定）** — the old product/container itself has no current existence decision.
- **PROTOTYPE ROUTE / NOT PRODUCT TRUTH（原型路由 / 不是产品真相）** — a route/page exists in source scaffolding, but implementation presence is not evidence of final product IA.
- **HISTORICAL ONLY（仅历史）** — superseded old product direction.

# 9. Prototype/source routes that must not be mistaken for final IA / 不得把源码原型路由误当最终信息架构

The source-native scaffold currently contains or documented validation routes such as:

- `/`;
- `/articles`;
- `/articles/[slug]`;
- `/issues`;
- `/issues/[slug]`;
- `/topics`;
- `/topics/[slug]`;
- `/collections`;
- `/collections/[slug]`;
- `/search`.

Rules:

1. source-code existence proves **prototype implementation**, not final Product Architecture;
2. where the underlying product surface is independently confirmed (Home, Article/Publication reading, Issue, Topic, Search), the route may remain a useful implementation candidate but is not frozen by provenance;
3. where the underlying container is not fully confirmed (e.g. exact `/articles` archive IA, exact `/collections` product), route existence does not upgrade it to current product truth;
4. legacy preview-only routes such as `/vip-library`, `/reading-room`, `/letters`, `/custom-reading`, `/custom-ebook` carry zero current existence authority unless separately revalidated.

# 12. Mandatory provenance gate / 强制来源闸门

Before any legacy-named page/module/product is designed:

```text
Concept appears
→ classify origin: post-reset / legacy / prototype-only
→ find explicit post-reset existence evidence
→ distinguish need/capability from container/page/name
→ if product existence is unproven: mark UNRESOLVED
→ discover user/product need without using the legacy container
→ only then decide whether a distinct product/page/module is warranted
```

Implementation/code/preview existence never substitutes for this gate.
