# Membership Re-entry Review #1（会员重启检查 #1）— Early Co-builder Historical Evidence Resolution V1
# 会员重启检查 #1——早期共建历史证据结论 V1

> **Status（状态）:** USER-CONFIRMED / RESOLVED（用户确认 / 已解决）
> **Implementation（实现）:** NOT AUTHORIZED（未授权）
> **Merge（合并）:** NOT AUTHORIZED（未授权）

## 1. Evidence-backed and typed history（有证据、按类型的历史）

Early Co-builder（早期共建者） history must be grounded in evidence appropriate to the specific history type.

The platform should not grant a vague global founder/co-builder label（模糊统一创始 / 共建标签） without explainable historical basis.

## 2. Different history types use different evidence standards（不同历史类型使用不同证据标准）

The six independent history families retain type-specific evidence logic:

- Early Presence（早期在场）;
- Financial Support（资金支持）;
- Quality Publishing / Knowledge Participation（优质发布 / 知识参与）;
- Network Growth（网络增长）;
- Product Co-building（产品共建）;
- Cultural Recovery / Project Participation（文化寻回 / 项目参与）.

No one universal score / threshold（统一分数 / 门槛） controls all six.

## 3. Self-claim is allowed as input, not auto-confirmed truth（允许自述作为输入，但不能自动变成事实）

A user may submit a historical claim（历史主张）.

But:
> **Self-claim（自述） != Confirmed Historical Record（已确认历史记录）.**

Confirmation may use platform logs, project records, attribution records, payment/support records, publication history, referral evidence or other relevant evidence.

## 4. Confirmed history should preserve provenance（确认历史应保留来源溯源）

Where practical, confirmed historical records should preserve:
- what happened（发生了什么）;
- time / formative stage context（时间 / 形成阶段上下文）;
- related work / project / activity（相关作品 / 项目 / 活动）;
- evidence source（证据来源）;
- later correction / dispute history where needed（必要时的后续纠正 / 争议历史）.

The goal is explainability, not a mysterious badge（目标是可解释，而不是来历不明的徽章）.

## 5. Lightweight by default（默认轻量）

Prefer:
- automatic durable records where reliable platform data already exists（已有可靠平台数据时自动保留）;
- lightweight confirmation where context is clear（上下文清楚时轻量确认）;
- manual review only for ambiguous or consequential claims（只有模糊或高影响主张才人工复核）.

The system should not become a Founder Court（创始者法庭） or heavy administrative process.
