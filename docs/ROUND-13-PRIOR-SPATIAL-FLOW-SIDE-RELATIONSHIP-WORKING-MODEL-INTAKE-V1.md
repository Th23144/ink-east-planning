## 2. Relationship insights worth carrying forward（值得继承的关系洞察）

### R1 — The relationship is not “content site + store”（不是“内容站 + 商城”）
The useful relationship hypothesis is deeper than a marketing funnel.

Potential conceptual bridge:
- Knowledge ↔ Object（知识 ↔ 物件）
- Culture ↔ Practice（文化 ↔ 实践）
- Understanding ↔ Ownership / Use（理解 ↔ 拥有 / 使用）

This is a hypothesis to test, not yet final architecture.

### R2 — Each product must stand independently（两个产品必须各自独立成立）
Spatial Flow（空间流）must be understandable and valuable without requiring prior Ink & East（墨与东方）education.

Ink & East（墨与东方）must remain valuable even to a user who never buys from Spatial Flow（空间流）.

This is compatible with the current independence premise.

### R3 — The relationship should be bidirectional（关系应当双向）
Possible path:
- Ink & East（墨与东方）knowledge / cultural context → real-world object / practice in Spatial Flow（空间流）;
- Spatial Flow（空间流）object / material / craft / use → deeper knowledge / context in Ink & East（墨与东方）.

The relationship should not be reduced to one-way traffic conversion.

### R4 — Editorial Independence（编辑独立性）is a likely hard boundary
If Ink & East（墨与东方）covers a craft, material, maker, object or practice that Spatial Flow（空间流）also sells or commercially benefits from, the architecture must prevent commercial interest from silently controlling editorial judgment.

This includes future questions around disclosure, recommendation, criticism, selection and commercial influence.

### R5 — Spatial Flow（空间流）may represent a physical-world / material-practice counterpart（现实物质 / 实践对应端）
The useful part of the prior model is not that Spatial Flow（空间流）“belongs to” Ink & East（墨与东方）, but that some cooperation may connect:
- cultural/knowledge context（文化 / 知识语境）;
- material / craft / object（材料 / 工艺 / 物件）;
- use / care / space / ownership（使用 / 照护 / 空间 / 拥有）.

Whether this is the central relationship is still unresolved.

### R6 — Object-centric Commerce（以物件为中心的商业）may create a natural collaboration surface
Spatial Flow（空间流）may treat objects as richer than a SKU（库存单位）:
- materiality（材质性）;
- craft（工艺）;
- provenance（来源）;
- maker（制作者 / 工坊）;
- care（照护）;
- compatibility / configuration（兼容 / 配置）;
- space / use（空间 / 使用）;
- cultural context（文化语境）.

Some of these dimensions may overlap with Ink & East（墨与东方）knowledge/research work, creating a potential collaboration surface.

This remains a Spatial Flow-side strategic hypothesis, not a locked cross-product data model.

### R7 — Depth should be available, not mandatory（深度应可获得，但不应强制）
Cross-product connection should not force:
- a Spatial Flow（空间流）buyer to study long cultural material before purchasing;
- an Ink & East（墨与东方）reader into a commercial funnel.

Depth may be available when desired.

### R8 — Long-term value may come from accumulated systems, not superficial cross-linking（长期价值可能来自系统积累，而非简单互链）
Possible future shared/collaborative value may involve:
- source/provenance relationships（来源 / 溯源关系）;
- material/craft knowledge（材料 / 工艺知识）;
- maker / workshop relationships（制作者 / 工坊关系）;
- object documentation（物件记录）;
- care/use knowledge（照护 / 使用知识）;
- real-world projects（现实项目）.

This does **not** authorize shared infrastructure or one unified graph.

### R9 — Public relationship wording remains unresolved（对外关系措辞仍未决定）
The prior model explicitly did not settle:
- parent/sub-brand status（母 / 子品牌关系）;
- legal/company relationship（法律 / 公司关系）;
- public labels（对外称谓）;
- shared account/data/commerce systems（共享账户 / 数据 / 商业系统）.

These remain open.
