## 1. What is and is not a knowledge-correction case（先界定适用范围）

正式的知识事实／来源纠错只在内容确实承担相应知识、来源、档案、编辑或重要事实责任、并且有实际依据和需要时才适用。普通用户的文化解读、不同思想主张、个人随笔和一般争论**不会仅因有人不同意而被自动立为正式案件**；日常讨论、反驳、作者自行修订及基础安全规则继续正常适用。

内容属于以下其他治理路径时，**不因共享一份举报而自动被纳入知识结果**：
- 正式 Candidate / Recognized Work（候选／认可作品）的关键评审依据复核：走独立、针对作品／版本的 Recognition（认可）程序；
- 经独立证实的违规、诈骗或滥用：走 Safety / Conduct Moderation（安全／行为审核）；
- 身份、贡献者资格或能力审查：依据相关独立资格规则；
- 权利／许可／资产可用性改变：按对应现行来源权利与可用性规则处理，而不是当然认定过去的知识事实错误。

**是否受理／归属何种程序**是分流或流程问题，**不是**下面三种知识事实结案结果中的一种。

## 2. Three confirmed substantive knowledge outcomes（三种已确认的知识事实结案结果）

以下 A/B/C 采用易读的**新正式编号**；与旧 V1／V2 的 A/C/D 一一对应。编号改变**不引入新类别**。

### A — Confirmed Error（确认错误）
对适用范围内的日期、引文、版本、转录、来源、归属或其他可核实的重要事实，有足够依据确定记录／主张确有错误。

- 相应负责方应按既有权限纠正自己负责的记录，保护各版本原貌、来源依据、重要修订历史。
- **“发现／确认错误”与“已经完成更正”分开记录**。不能尚未修完就声称已纠正。
- 独立作者有适当回应和自行修订机会；平台不得暗改其正文或主观观点。必要的有证据说明遵循已确认的范围和责任约束。
- 不因错误成立自动认定作者故意造假、违规或失去作品认可。

### B — Material Fact / Source Undetermined（重要事实／来源暂无法确定）
在实际适用的来源记录、编目、归属或重要可核实事实中，已有合理依据表明存在**需要如实保留的实质性不确定性**，但现有证据不足以给出可靠定论；也包括可信来源证据之间确实无法解决的重要事实冲突。

- 如实记录当前证据及重要不确定性；根据平台责任和下游依赖程度，必要时在相应来源记录上作范围适当的说明。
- 不强制为哲学、文化、艺术理解分歧判胜负；不得仅因举报使普通作品带有污名化标签。
- 出现实质新证据、情况变化或重要程序错误时，按既有复核机制重新评估。

### C — Correction Request Not Sustained（纠错请求不成立）
对于属于可审查事实范围的具体纠错主张，相关材料没有充分支持本次纠错要求，且没有合理依据要求将涉及的记录改为“重要事实未定”。

- 本次不据此修改原记录或公开贴负面争议标签；在适当情况下可向提出者解释未采纳的原因。
- **“本次纠错请求未得到支持”不等于“原记录所有内容均被证明绝对正确”**。
- 它与 B 不因简单的“举报者证据少”划线：真正重要的事实自身有实质不确定性时，应按 B 处理，而不是机械拒绝。

## 3. Non-exclusive by individual factual claim（逐条事实结论，案件整体不强制单选）

同一申请可能同时含有不同的可核实事实／Claim（主张）。对不同主张**可分别形成 A、B、C 不同结果**；不能强制整份申请仅有一个互斥的“真伪等级”。

例如：一篇由平台维护的编目记录，一处引文经证实抄错可为 A；另一处作者归属仍有可信证据冲突可为 B。

三种类型是**知识事实层面的结果**，不取代 Received / Under Review / Closed / Reopened（已受理／处理中／已结案／重新开启）等原有程序状态，也不表示所有案件必须在某个固定时限内强行判断。

## 4. Preserve confirmed correction, review and authorship boundaries（原有已确认边界不变）

- 保留 Propose → Triage → Evaluate → Resolve → Record → Revisit（提出→分流→评估→处理→留痕→复核）这一产品级原则流程，但不新设全站强制审查程序。
- 纠错提案、编辑权、事实纠错决定权与作品认可权各自分离。对适用范围内的重大纠错，作者有合理回应机会，但不能无限阻止平台依法／依证据修改自己负责的来源事实记录。
- 重大变更保留适度证据、理由、时间与版本记录；轻微错字不必每次醒目公告。隐私／敏感证据不能仅为透明而公开。
- 高影响决定沿用已有人工／独立复核、申诉与真实恢复原则；作品认可如因关键事实动摇需单独复核，当前有效状态与历史曾获认可的事实均要准确呈现，不连坐无关作品或作者身份。
- 原典来源的真实异文、后补标点、译注和多元研究观点继续保持各自的身份与来源；作品认可或大众热度不等于原典真理。

第七轮的不同 Claim、异本、争议证据和来源记录可长期并存的能力继续有效；本结论不删除它们，只排除把普通解读差异强行转化为正式审理结案。

## 6. Confirmed vs deferred（已确定与尚未授权）

**本次正式确认**：三种知识事实结案结果 A/B/C；重要来源事实与普通解释分离；同一申请多主张分别结论；与违规、认可、权利、流程状态的独立边界；原有申诉和修订原则继续有效。

**仍暂缓**：具体证据量化阈值、人员分工、操作时限、表单和数据库设计、公开标签／提示组件的具体 UI、自动审核规则以及其他技术细则。本次确认不授权新增全站事实审查、全局置信度评分、普遍负面争议徽章、强制纠错所有用户观点或新的处罚体系。
