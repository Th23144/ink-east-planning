## 1. 产品治理的总边界（S01/S06/S07/S08/S09）

1. Ink & East 是开放发表、文化研究及社区讨论平台。普通用户可以依法发表随笔、主观观点、个人经历、文学虚构、夸饰、古籍理解及不同文化诠释。普通发表不等于平台核实每句话、作者必须证明亲历或通过学术审核。
2. 正式 Candidate / Recognized Work 评审、平台负责的 Canonical / Source-backed 资料完整性和基础 Safety / Conduct 处理是不同的管辖路径。正式评审只核查作品类型和评价依据真正相关的重要主张，不强制逐句核验，也不要求思想、哲学或艺术解读只有一种正确答案。
3. 规范来源层保留古籍原文、底本／真实异文、馆藏、实物与数字影像、转录、归属及修订溯源。译文、后补标点、编纂、注释与独立解读有各自署名和归属，可同屏阅读但不能继承唯一原典权威。
4. 基础合法性、欺诈、骚扰、冒充、侵权、安全和真实重大伤害风险规则独立适用全站；不把普通观点分歧或普通作品虚构本身自动处罚。
5. 非等价关系不可抹除：Published ≠ Verified ≠ Candidate ≠ Recognized ≠ Canonical；举报 ≠ 事实已证实；纠错 ≠ 处罚；普通推荐／热榜／付费加热／编辑精选 ≠ 正式作品认可。认可只属于相应作品／版本，不自动转为作者等级或账户权威。

## 2. 四类治理管辖与决定权（S01/S04/S05/S06/S07）

1. A 安全／行为审核：违法、滥用、欺诈、骚扰与危害行为；B 事实／来源纠错：文献版本、引用、事实及来源维护；C 质量／正式认可审查：相关作品的质量和认可依据；D 身份／资格／能力审查：特定身份、Contributor Qualification、组织验证或能力。各自有责任与证据，不会因一项成立自动推出其他结论。
2. Report / Correction Proposal（报告／纠错建议）、Editing Authority（编辑权）、Correction Decision（纠错决定权）与 Recognition Authority（作品认可决定权）分离。提供证据不能自动覆盖他人文章，也不自动撤销认可。
3. 正式纠错强度依具体内容的来源与编辑责任、主张性质、证据、受众依赖和实际影响决定；不靠会员、作者名望、内容热度或 Recognized 身份单一判断。普通社区优先作者自己修改、他人质疑与交流，不被普遍纳入正式知识审查；如确有严重现实伤害风险或高影响、需他人依赖的关键事实主张，可以**因实际风险**采取相称的独立核查，不能因此普遍审稿。
4. 适用的重要事实更正，作者应获合理回应机会；但不能无限期阻止平台修复由平台负责且已证实错误的原典记录。不得把独立作者的主观观点暗改成平台裁判的版本。
5. 多元文化解读可以长期共存。早期 Good-faith Dispute（善意争议）措辞不等于普通哲学分歧必须立案、人工裁决或挂公开负面争议标签。

## 3. 知识纠错的完整流程和正式三结果（S01/S04/S05/S06/S09/S13）

1. 原则性流程：Propose → Triage → Evaluate → Resolve → Record → Revisit（提出→分流→评估→处理→留痕→复核）。可以轻量提出纠错，正式处理时应针对具体事实／来源 Claim 和实际可核实证据。
2. 三种知识事实结果：**A Confirmed Error（确认错误）**，即有足够依据认定适用范围内重要事实／转录／出处等确错；**B Material Fact / Source Undetermined（重要事实／来源暂无法确定）**，即客观存在应当保留的重要未决来源或事实问题；**C Correction Request Not Sustained（纠错请求不成立）**，即本次纠错要求缺乏足够支持，同时没有重要未决事实应进入 B。
3. A 的确认错误与是否已经实际更正应分开记录。B 不能把普通观点不同变成思想裁判。C 不代表原记录一切绝对正确。不同事实 Claim 可以独立得到 A/B/C，而不能强制整份申请只选一个。
4. 受理／处理中／结案／重新开启是程序状态，独立于 A/B/C。单独证实的违规、Recognition 复核、身份资格决定、版权权利变更不混入三种知识结果。旧版五类结果及旧 A/C/D 编号仅作历史。
5. 重要修订视实际责任记录改动、时间、理由、证据及必要历史；普通错字可轻量处理。内部来源历史与公开说明相互独立，不能为了透明公开敏感私密证据；真实不同底本及解释不强行合并为一个“真本”。

## 4. 执法比例、范围和程序保障（S01/S02/S03/S05）

1. Object-level、Capability-level、Role/Qualification-level、Account-level 是四种受影响范围，不是必须逐级升级的统一惩罚阶梯。采用 Narrowest Effective Action（最窄有效处理），依严重性、危害、规模、反复、可逆性、合理可知意图、规避与善意纠正作判断；重大紧迫风险仍允许必要的立即强措施。
2. 优先考虑风险相称、可复核及适当有限期措施；严重持续滥用可长期限制。扩大受影响范围时需说明证据、新风险、较窄措施不足、期限及申诉渠道。纠错不因本身导致账户、角色或资格处罚。
3. 低影响措施可轻量复核；中影响有正式申诉渠道；高影响行为需更强程序保护。原决议**列明的特定高影响事项**（如长期／永久账户限制、重要 Contributor Qualification／Organization Verification／Recognition 撤销、重大来源真伪／版本归属争议，以及自动机制不能可靠理解上下文的案件）按适用范围要求 Human Review（人工复核），而**不是所有普通争论都触发人工复核**。高影响申诉不能只由原决定者或原自动化路径审查自己；具体人员安排留待运营。
4. 完成全面复核后，无实质新材料的重复申诉可以拒绝无限重审；新证据、重大情势变更或程序错误可再次开启。申诉成功必须实际恢复适当的可见性、能力、资格、认可、验证及相关状态，保留必要历史，不仅口头宣布成功。
5. 不建立单一全局账户信任分、不由商业付费/会员/机构/名气购买更有利的处理或申诉结果，不因一次纠错自动剥夺无关资格。

## 5. 举报防滥用、Candidate 临时保护和独立编辑责任（S02/S03/S07/S09/S14）

1. 举报数量、多个账号、截屏、AI 编辑素材、名人／机构声明不自动等于独立事实证据。多账号提交同一伪造材料不能累加成多个独立来源；误判举报和经独立认定的恶意操纵治理系统应区分。
2. Normal／普通作品与 Nomination Eligible / Exposure / Formal Nomination 不因被人质疑，就自动进入 Candidate/Recognized 的事实审查或临时认可限制。真正进入 Candidate 或 Recognized，且重要完整性疑点获得独立支持、继续有关官方认可背书存在实际风险时，才可能考虑有限期、最窄范围、可撤销的评审／相关官方主动推广调整，不得把尚未证实造假公布为既定事实。
3. 独立官方编辑精选、专题主动推送、Issue 策展并非正式 Work Recognition。若平台当前编辑背书确有证实的重要风险，可狭窄调整该编辑行为；不能把普通文章因此提升为 Candidate，不能将一般算法推荐、阅读量或仅被编辑提及当作正式认可。
4. 临时措施与调查期限分离；重复举报或仍在调查不构成无限续期依据。风险依据被推翻，恢复正常的有效认可／编辑推广资格和下游状态；不保证补偿自然流量。可核实原定官方精选档期被错误取消时可以考虑恢复展示机会。
5. 认可曾经被授予的历史事实与当前认可有效性不同。对关键证据证实失效的作品/版本，走独立 Recognition 复核，当前搜索、推荐和官方状态不得继续假装有效，同时不得秘密删除真实的原期刊收录、原认可记录、作者署名与可审计历史。

## 6. 作品认可作者的三阶段自主权（S15/S16/S17）

1. 被普通发表、发现、读者推举以及 Formal Nomination 不需要先签署 Candidate 参加协议；但**作品真正进入 Candidate 正式评审前，必须取得有效作者参与同意**。作者的沉默、热门或被推荐不等于同意。拒绝不代表作品低质量、违法或其普通发表权消失。
2. **Candidate 进行中**，作者可主动退出正式评审；退出与 Not Recognized、审查失败、处罚或造假不同，不能继续自动晋升 Recognized。普通文章、正常发现、必要审核历史与独立安全／权利责任继续有效。
3. **获得 Recognized 后**，作者可以终止本人当前正式认可展示／参与。对**单独作者作品**或依法依有效权限由作者处置的整件作品，应准确停止对应的当前认可标识和官方认可推广；但对**多作者共同作品**，一名作者退出自己的参与**不自动取消整件作品的认可**，须结合下文第 7 节的作品级授权及实际权利／关键证据是否改变另行判断。保留真实的历史授予时间和版本；普通发表与独立期刊历史不因退出自动删除。Recognition Invalidated / Not Recognized / Voluntary Withdrawal / Editorial Inclusion 是不同原因。
4. 不规定强制说明退出理由、统一冷静期、手续费、永久不可重新参加或公开负面标签。具体通知、旧版资格再利用、重入路径、权限与恢复同步待设计。

## 7. 多作者作品和入 Candidate 同意（S15/S16/S17/S20/S21）

1. 每位真实作者的个人参与权／退出权，与整件共同 Work 的候选或认可处置权限分离。署名、提交者、运营者或组织代表身份不自动拥有替所有作者处置整件作品的权限。
2. 一位共同作者退出本人的参与，不自动撤销整件合作作品的认可，也不自动把所有其他作者退出；整体状态变更需合法、有效且限域的作品级授权或正当的共同作者争议决定。如果作者退出使必要版权授权、核心来源证据或作品完整性改变，须独立核查原认可依据是否仍然有效，不能机械保留也不能机械撤销。
3. **共同作品首次正式进入 Candidate**：真实作者 A、B 同意，而 C 明确不同意且没有对该事项进行有效代表授权，不能绕过 C 将整件合作作品进入正式评审；先解决授权与参与问题。C 沉默又无有效授权时不能推定同意；普通发表及他人推举记录不因此自动取消。
4. 此处没有批准所有作者每次必须亲自点击、固定投票比例、主作者天然高权、任一署名人对已获认可共同作品的永久单方否决、默认代理授权或全体实名认证。授权材料、代理操作与撤回、无法联系、投诉、重入、UI 等实务仍待定。

## 8. 成熟文化表达、艺术与长期商业排除（S10/S11/S12/S18）

1. Ink & East 是**允许成熟文化表达的综合文化平台**，不是成人娱乐内容生产／商业平台。**长期明确排除的产品方向**是不建设专门成人内容收费订阅、私密露骨影像商业化、付费成人私聊、OnlyFans 式成人创作者经济生态；这不是仅限首版的延期。只有未来用户**明确作出重大平台定位变更**才能重新考虑，不可悄悄以增长实验启用。
2. 普通合法成人题材小说／文学，包括较直接性描写，原则上可发表，但不得仅因互动高就自动进入普通综合首页的被动推荐。未主动选择成人内容的读者不应在 Home / Explore / Trending / Related / 通知／缩略图中意外看到成人主体内容；一次点击或长期成人阅读不等于许可算法让文化首页成人化。**对明确主动选择成人浏览的人，成人主题能否、怎样进入综合首页的细化机制仍未定**；可能另议主动进入的非付费分类／搜索界面，不能由此推出已批准成人订阅或专门推荐产品。
3. 米开朗基罗《大卫》等真实艺术史裸体作品，以及合法独立摄影师的正规人体艺术摄影，不能仅凭裸体或作者无名而按成人娱乐封禁。可在艺术领域和主动艺术搜索正常被发现；一般首页的明显正面裸体预览要克制。完整作品与缩略预览属于不同展示决定。
4. 成年人合法、明显挑逗或性暗示但没有直接展示真实性行为的裸体／亲密摄影，**可发表、可主动检索和直接访问，但不可被平台主动推荐**，包括热榜、主动相关推荐、自动连播或付费加热等变通。作者自标艺术、名气和热度不改变该分发资格。
5. 合法成熟文化允许发表、允许被主动发现、允许被主动推送与允许商业化四个轴相互独立。X/Reddit 不作为平台照搬尺度。成年人同意、原始影像使用许可、相关法律及对未成年人剥削和未经同意私密影像的排除底线始终有效。**成人题材作品能否进入正式 Work Recognition 以及具体评价条件尚未由该内容分类结论批准**。

## 9. 明确真实性行为影像的窄文化例外（S12/S18/S19/S22）

1. **不开放以情色消费或观看真实性行为为主要目的的普通图片／视频上传**。作品实际具有明显情色消费导向，或真实性行为成为主要观看内容且不相称于独立文化用途的，原则上排除特殊资格；不设置 49%/51% 固定比例，也不单凭观看者可能有生理反应否定严肃文化作品。
2. 合法、确有历史、文化、严肃纪录、研究或实验艺术用途的特殊影像，只保留**受限个案资格评估的可能**，作者头衔、博物馆身份、名望不能是普通研究者的统一准入门槛，自称艺术也不自动通过。严肃电影中少量实质相关真实镜头只表示**可考虑资格评估**，不代表任何电影自动取得公开传播资格。
3. **E06 已批准**：申请这种特殊资格、直接展示真实明确性行为的影像／片段必须公开前审核通过，未批准时不能经页面、播放器、缩略图、直链或分享向公众开放。如果正文自己符合普通规则，正文可先正常发表，受限视频独立等待审核，不能把整个普通文化研究都改成先审后发。
4. 合规历史春画／古籍绘画引用，不仅因描绘明确行为就自动进入面向真人性行为影像的特殊预审流程；其来源真实性、版权及合理敏感展示／年龄条件照旧适用。通过资格审核也不取得普通首页推荐、热榜、自动连播、付费加热资格。
5. **E07 的“算认可吧”**代表在产品架构层面沿用既有资格、安全、版权、E06 公开前审核、重大复核/申诉原则，接受实施细节后置；并不代表批准审核员人数、申请表、证据阈值、办理时限、限龄服务商、隐私保存方案及正式审核系统上线。当前相关业务不能直接对外运行。

## 10. 阅读提示、年龄限制与公众暴露（S11/S12/S18/S19/S22）

1. 对符合发表资格的受限资料，应在敏感内容实际暴露之前设置必要阅读提示、敏感预览保护和适用法域要求的有效年龄措施。简单“我已成年”勾选若不满足法定要求，不能代替正式核验。
2. 阅读警告不扩大原有发表、推荐或商业资格；被允许阅读也不等于平台必须主动展示给未选择的读者。具体地区、年龄标准、保护技术、UI、隐私实现尚未选定，不自动要求所有平台注册用户上传证件。
3. 第八轮的**官方 Domain／Topic／Place 与未来可能出现的用户自建 Community／Group／Space** 是不同层级：后者在早期 V1 **仍明确暂缓**，不能写成已经正式上线或得到全站治理权限。倘若日后引入，加入／关注用户空间也不自动授予管理权，更不能由空间自行放宽已确认的全站敏感内容、权限及分发边界。

## 11. 六项已确认跨轮修正（S07/S08/S09）

- RP1：不因普通文化诠释不同而自动开正式来源争议案件。
- RP2：原典来源底本与后人译文、标点、注释分别署名溯源，但可同屏展示。
- RP3：真实正式 Candidate／Recognition 的关键依据核查不能自动套用全部普通帖子。
