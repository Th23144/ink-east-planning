# 1. New system identity（新系统身份）

Open Cultural Contribution & Recovery（开放文化贡献与寻回）is a **core knowledge / cultural recovery capability（核心知识 / 文化寻回能力）**, not a Monetization Product（商业化产品）and not a reader-facing paid Service（面向读者的付费服务）.

Its bidirectional structure is:

```text
Ink & East → World（墨与东方 → 世界）
Public Request / Source Call / Research Request
（公开求助 / 资料征集 / 研究求助）

World → Ink & East（世界 → 墨与东方）
Lead / Knowledge / Material / Collaboration
（线索 / 知识 / 资料 / 合作）
```

Then:

```text
Intake（接收）
→ Provenance Review（来源复核）
→ Rights / Privacy / Sensitivity Review（权利 / 隐私 / 敏感性复核）
→ Authenticity / Identity Assessment（真实性 / 身份判断）
→ Documentation / Digitization（记录 / 数字化）
→ Restoration / Reconstruction（修复 / 重建）
→ Research / Translation / Annotation（研究 / 翻译 / 注释）
→ Institutional Referral / Handoff where applicable
  （必要时机构转介 / 移交）
→ Open Publication / Public Access where permitted
  （在允许范围内开放发布 / 公共访问）
→ durable provenance / contribution history
  （长期来源 / 贡献历史）
```

# 2. Round 4（第四轮）Contributor（贡献者）reconciliation

## 2.1 Material conflict found（发现的实质冲突）

Existing architecture uses Contributor Qualification（贡献者资格）as a scoped competence / professional-contribution qualification.

The new cultural-recovery system involves many participants who must **not** be labeled as platform Contributor（贡献者）merely because they helped. Examples include people who:

- discovers a source（发现资料）;
- provides a lead（提供线索）;
- supplies family/local knowledge（提供家族 / 地方知识）;
- lends or deposits material（出借 / 寄存资料）;
- provides scans/images（提供扫描 / 影像）;
- translates / transcribes / restores（翻译 / 转录 / 修复）;
- facilitates institutional contact（促成机构联系）.

These two meanings must **not** collapse.

### New hard separation（新增硬分离）

> **Recovery Participation Role（寻回参与角色） != Contributor Qualification（贡献者资格）.**

A person can make a valuable Source Contribution（资料贡献）or Discovery Contribution（发现贡献）without holding Contributor Qualification（贡献者资格）.

Likewise, holding Contributor Qualification（贡献者资格）does not automatically make every submitted source authentic, lawful, important or publication-ready.

---

## 2.2 Recovery Attribution（寻回归因）becomes first-class

The platform must be able to attribute actual Recovery Participation Roles（寻回参与角色）, for example:

- Discoverer（发现者）;
- Source Provider（资料提供者）;
- Knowledge Contributor（知识贡献者）;
- Material Holder（资料持有人）;
- Donor（捐赠者）;
- Depositor（寄存者）;
- Photographer / Imager（摄影 / 影像记录者）;
- Digitization Contributor（数字化贡献者）;
- Transcriber（转录者）;
- Collator（校勘者）;
- Translator（翻译者）;
- Researcher（研究者）;
- Restorer / Reconstruction Contributor（修复 / 重建贡献者）;
- Institutional Connector（机构联络促成者）;
- Custodian / Holding Institution（保管者 / 收藏机构）.

Exact public vocabulary（最终公开词汇）remains evolvable.

### Important boundary（重要边界）

Recovery Attribution（寻回归因）:

- records what someone actually contributed（记录真实贡献）;
- may support a Profile / Portfolio（个人资料 / 作品与贡献档案）;
- does **not** automatically create Expertise Scope（专业范围）;
- does **not** automatically create Contributor Qualification（贡献者资格）;
- does **not** automatically create Work Recognition（作品认可）;
- does **not** automatically create source authenticity（资料真实性）;
- does **not** automatically create ownership / rights（所有权 / 权利）.

---

## 2.3 Existing Round 4 strengths that survive

Round 4（第四轮）already supports:

- Field / Local Knowledge（田野 / 地方知识）as a legitimate evidence path;
- Institution / Partner（机构 / 合作方）relationships;
- co-creation / research / project opportunities（协作创作 / 研究 / 项目机会）;
- pseudonymous public identity（公开笔名 / 化名）;
- scoped identity / credential verification（范围化身份 / 资历验证）;
- authorship / organization / platform identity separation（作者身份 / 组织 / 平台身份分离）.

These all fit the new system.

### Round 4 amendment required（第四轮需要的修订）

Old “editorial commissioning（编辑约稿）” examples are historical wording and should no longer be used as a current Contributor Opportunity（贡献者机会）concept.

The broader valid direction is:

> Contributor / user / institution participation may include **source discovery, knowledge contribution, research collaboration, preservation/digitization work and other scoped cultural-recovery collaboration（资料发现、知识贡献、研究合作、保存 / 数字化工作及其他范围化文化寻回合作）**.

If editors directly seek help from a known person or institution, use the actual current action label such as Directed Request（定向求助）, Research Collaboration（研究合作）or Editorial Collaboration（编辑合作） rather than reviving Commission（约稿）.

# 3. Round 7（第七轮）Knowledge Graph & Provenance（知识图谱与来源溯源）reconciliation

## 3.1 Overall result（总体结果）

**STRONG FIT / NO FUNDAMENTAL CONTRADICTION（高度兼容 / 无根本冲突）.**

Round 7（第七轮）already contains most of the data/provenance semantics required by the new system.

Especially relevant existing rules:

- Work / Edition / Source Item / Segment separation（作品 / 版本 / 来源载体 / 片段分离）;
- physical Source Item（实体来源载体） != Digital Surrogate（数字替代物）;
- provenance（来源溯源） != truth certification（真实性认证）;
- OCR / transcription / collation / translation / restoration provenance（OCR / 转录 / 校勘 / 翻译 / 修复来源记录）;
- typed roles such as holding, digitization, transcription, photography and data provision（保管、数字化、转录、摄影、资料提供等类型化角色）;
- source provenance / rights / source assessment separation（来源 / 权利 / 来源评价分离）;
- donor restrictions（捐赠者限制）;
- privacy/publicity / cultural sensitivity / third-party rights（隐私 / 公开权 / 文化敏感性 / 第三方权利）;
- broken-link / withdrawn-source historical provenance（失效链接 / 撤回来源的历史溯源）;
- item-level rights specificity（单件级权利优先）.

The new system therefore does not require a new ontology from zero.

---

## 3.2 Required extension: Recovery Provenance（寻回过程溯源）

Round 7（第七轮）tracks the object and transformations well, but the new system requires the **recovery journey itself** to be representable where material.

Potential typed events / relations（潜在类型化事件 / 关系）include:

- discovery（发现）;
- lead submission（线索提交）;
- initial contact（首次联系）;
- holder declaration（持有人声明）;
- temporary deposit / loan（临时寄存 / 借用）;
- custody change（保管变化）;
- documentation event（记录事件）;
- condition assessment（状态评估）;
- digitization event（数字化事件）;
- restoration / reconstruction event（修复 / 重建事件）;
- rights permission event（授权事件）;
- institutional referral（机构转介）;
- physical handoff / accession（实体移交 / 入藏）;
- public release（公开发布）.

Not every object must use every event.

### Canonical rule（核心规则）

> **Object custody may change; recovery and contribution provenance must remain reconstructable where lawful and appropriate（实体保管关系可以变化；在合法且适当的情况下，寻回与贡献来源链必须可重建）.**

---

## 3.3 Ownership / Holding / Custody / Rights must stay separate

The new physical-original workflow creates a crucial separation:

- Owner（所有者）;
- Holder / Custodian（持有人 / 保管者）;
- Holding Institution（收藏 / 保管机构）;
- Temporary Custody（临时保管）;
- Digital Provider（数字提供方）;
- Rights Holder（权利人）;
- Donor（捐赠者）;
- Depositor（寄存者）;
- Receiving Institution（接收机构）.

These must not be collapsed into one “source owner（资料所有者）” field.

A museum / archive / library may physically hold an item without owning every associated copyright/right.

A private owner may allow digitization without donating the original.

Donation（捐赠）does not automatically mean unrestricted public reuse.

---

## 3.4 Physical original handoff rule（实体原件移交规则）

Ink & East（墨与东方）is not assumed to be the final permanent repository（永久保管机构）for culturally significant physical originals（具有文化价值的实体原件）.

Where lawful, appropriate, holder-authorized and institution-accepted（合法、适当、持有人授权且机构接受）:

> long-term physical custody（长期实体保管）should normally transition to a Qualified Institution（合格机构）with appropriate preservation / research / public-service capacity（保存 / 研究 / 公共服务能力）.

Ink & East（墨与东方）may preserve:

- digital surrogate（数字替代物）;
- research record（研究记录）;
- transcription / translation / annotation（转录 / 翻译 / 注释）;
- recovery provenance（寻回溯源）;
- Recovery Attribution（寻回归因）;
- institutional referral history（机构转介历史）;
- public-access representation（公共访问呈现）,

subject to rights / privacy / legal / cultural-sensitivity limits（权利 / 隐私 / 法律 / 文化敏感性限制）.

# 4. Round 11（第十一轮）Issue / Editorial Workflow（议题 / 编辑工作流）reconciliation

## 4.1 Main correction（主要纠正）

The historical pre-amendment Round 11（第十一轮修订前历史版本）treated the old Commission（约稿）term as a first-class Editorial Acquisition Route（一级编辑获取路径）. That framing is now superseded.

That is now too narrow / too strong as the main concept.

It should be amended from:

```text
Historical pre-amendment wording（历史修订前表述）:
Discovery / Submission / Open Call / [superseded old term] / Reader Letter / Collaboration
```

to conceptually:

```text
Discovery（发现）
/ Submission（投稿）
/ Open Call / Public Request（公开征集 / 公开求助）
/ Directed Request（定向求助）
/ Open Cultural Contribution & Recovery（开放文化贡献与寻回）
/ Reader Letter / Question（读者来信 / 提问）
/ Research / Editorial / Institutional Collaboration
  （研究 / 编辑 / 机构合作）
```

---

## 4.2 Cultural recovery intake（文化寻回接收）is not ordinary Submission（投稿）

A Source Lead（资料线索）, Material Deposit（资料寄存）, Donation（捐赠）, Oral Knowledge Contribution（口述知识贡献）or Institutional Referral（机构转介）must not be forced into the same object/workflow as an Article Submission（文章投稿）.

They may later generate:

- a Canonical / Source-backed object（规范 / 来源型对象）;
- an Edition / Source Item record（版本 / 来源载体记录）;
- a Digital Surrogate（数字替代物）;
- an Editorial / Teaching Work（编辑 / 教学作品）;
- a Research Object（研究对象）;
- an Issue inclusion candidate（议题收录候选）;
- a public recovery story / dossier（公开寻回故事 / 档案专题）.

But the intake itself is a separate provenance-bearing case（独立的带来源溯源案件）.

---

## 4.3 Issue（议题）may curate recovered material, but does not own it

An Issue（议题）may later include recovered/restored material, research, translations or explanatory works.

Existing Round 11（第十一轮）rules continue:

- Issue Inclusion（议题收录）is a Curation Relation（策展关系）;
- it does not clone the underlying object;
- it does not erase source provenance;
- it does not create Work Recognition（作品认可）;
- it does not change ownership / custody / rights;
- rights/privacy/legal changes may alter visibility without erasing permissible history.

This fits the new system directly.

---

## 4.4 Historical Commission（约稿）retirement（历史“约稿”退出现行架构）

Commission（约稿）is no longer retained as a current product-architecture concept.

When editors know the missing need and the person / institution they want to contact, the architecture should describe the real action directly:
- Directed Request（定向求助）;
- Research Collaboration（研究合作）;
- Source Recovery Collaboration（资料寻回合作）;
- Editorial Collaboration（编辑合作）.

Historical Commission（约稿）records remain only for Decision Provenance（决策溯源）.

# 5. Rights / privacy / cultural-sensitivity boundary（权利 / 隐私 / 文化敏感性边界）

Open（开放）in “Open Cultural Contribution & Recovery（开放文化贡献与寻回）” means:

> the system seeks broad public contribution and, where lawful/appropriate, broad public access to recovered knowledge.

It does **not** mean every received item is immediately public or unrestricted.

Possible restrictions include:

- personal/privacy material（个人 / 隐私材料）;
- family-sensitive archives（家族敏感档案）;
- sacred/restricted cultural knowledge（神圣 / 受限文化知识）;
- donor / depositor restrictions（捐赠者 / 寄存者限制）;
- copyright / neighboring rights（著作权 / 邻接权）;
- ownership disputes（所有权争议）;
- provenance uncertainty（来源不确定）;
- legal export / import / transfer controls（进出口 / 转移法律限制）;
- institution access restrictions（机构访问限制）.

Thus:

> **Open Access Goal（开放访问目标） != automatic publication entitlement（自动公开权）.**

# 7. New anti-collapse invariants（新增防混淆硬边界）

1. **Recovery Participation Role（寻回参与角色） != Contributor Qualification（贡献者资格）**.
2. **Material Holder（资料持有人） != Owner（所有者） != Rights Holder（权利人）**.
3. **Temporary Custody（临时保管） != Donation（捐赠） != Permanent Accession（永久入藏）**.
4. **Physical Original（实体原件） != Digital Surrogate（数字替代物）**.
5. **Provenance（来源溯源） != Authenticity（真实性） != Legal Ownership（法律所有权）**.
6. **Recovery Case（寻回案件） != Publication（发布）**.
7. **Donation / Deposit（捐赠 / 寄存） != automatic public-release permission（自动公开授权）**.
8. **Institutional Referral（机构转介） != institution acceptance（机构接收）**.
9. **Issue Inclusion（议题收录） != ownership / custody / Recognition（所有权 / 保管权 / 作品认可）**.
10. **Ink & East facilitation（墨与东方促成） != final legal/cultural-property authority（最终法律 / 文化财产认定权）**.
