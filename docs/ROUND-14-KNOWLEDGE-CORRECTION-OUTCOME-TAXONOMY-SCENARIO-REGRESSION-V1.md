## 2. Case checks（具体案例，全部为假设）

| # | 假设情景 | 应怎样处理 | 核查 |
|---|---|---|---|
| 01 | 两位读者根据相同《周易》原文形成不同的思想解释 | 普通讨论／并存；**不自动启动正式知识纠错** | PASS：无错误立案 |
| 02 | 普通游记写得夸张，旁人要求作者证明每一趟旅行，却没有独立证实的重大安全／欺诈问题，也未进入正式认可评审 | 普通反驳、作者自愿解释／修订；**不因质疑自动立案或要求票据** | PASS：符合 RP3 |
| 03 | 平台的某版本古籍转录漏掉一句，原影印底本可核实 | 对受影响的转录事实 **A 确认错误**；修订转录并留痕，**不改写原影像／底本** | PASS：符合 R7-B5 |
| 04 | 两个真实流传版本的文字本来不同，被用户说成“有一个肯定抄错” | 保留两个不同版本；**不存在事实错误就不强行选 A**。若平台将二者错误合并／标注为同一版本，该合并事实可进入 A | PASS：不同版本不是天然错误 |
| 05 | 平台馆藏记录的作者归属有两种可信证据，目前无法判断 | 属于重要来源事实时可给 **C 暂无法确定**，保留来源及不确定性，**不裁决思想解释** | PASS：保留重要来源争议 |
| 06 | 某人举报平台编目年代不对，只有一张无法核实的截图，现有可靠记录并无实质动摇 | 本次纠错申请 **D 不成立**；不公开污名化标记，也**不能宣称原记录永远绝对正确** | PASS：D 不等于真理认证 |
| 07 | 有两份可核查且彼此冲突的档案记录，足以使平台现有“确定作者”为真的表述失去确定性，但还不足以选定另一作者 | 实质来源事实待核，**C**；不因为举报人也无法证明替代作者就机械判 **D** | PASS：C/D 关键边界 |
| 08 | 平台专题说明把历史事件日期引用错了，原始来源可核实 | **A 确认错误**；负责方修订说明、保留重要变动依据；**错误认定与已完成修订分开** | PASS：事实结果与动作分离 |
| 09 | 同一份针对平台维护记录的申请，同时包含（甲）已证实的引文错字、（乙）尚无法确定的作者归属 | 按独立事实／Claim 分别记录：甲 **A**，乙 **C**；**不强迫整份申请只选一个唯一结果** | PASS（需要把该既有要求在 V2 写清） |
| 10 | 一篇已获得作品认可的旅行指南，经证据证明其获得认可所依赖的“亲自实地考察”关键材料为虚假 | 对适用的可核实记录纠正事实；**正式作品认可依其独立复核路径处理**，保存历史／现行状态；独立违规须另行证实，不能自动处罚账号 | PASS：不能把三种治理合并 |
| 11 | 平台引用错误来源后，又查明存在伪造材料的行为证据 | 来源事实有误可走 **A**；涉嫌违规**另走 Conduct**，是否违规须独立证实；不可把 E 塞进 A/C/D | PASS：纠错不等于处罚 |
| 12 | 某文献的现代数字化图像后来不再允许公开展示，但文献本身的版本事实没有变化 | 属于**权利／可用性状态变化**，并非自动属于 A/C/D 中的来源事实错误；保留允许范围内的来源历史，按现有权利规则处理 | PASS：权利状态与事实纠错分离 |
| 13 | 已结案的重要来源纠错出现足以改变判断的新证据 | 根据既有复核／重开规则**重新处理相应事实**，不是创造“重新打开”这个第四种事实结果 | PASS：流程与结论分离 |
| 14 | 某历史作者归属的新证据推翻了旧时代合理的推定 | 维护当前可靠的来源判断与历次证据／修订历史；**新证据不自动证明此前编目人员故意说谎**；具体事实究竟属 A 或 C 根据证据判断 | PASS：当前与历史责任分离 |

## 3. Cross-check / edge findings（发现的边界与是否需要新增规则）

1. **V2 的实质性遗漏（可定向补充）**：原 V1 §3 和 R7 的 Claim／证据模型允许同一请求包含不同独立事实。V2 尚未直说“**按具体主张分别给出结论，不能强制整张案件一个互斥结果**”。这是恢复已存在的边界，不是新增第四类，也不是新的用户授权。
2. **C / D 的相邻边界已可在原则层面区分**：重要来源事实本身确有实质不确定性可属 C；本次指控不成立且没有合理依据改变记录状态可属 D。具体证据阈值／决定权限仍未锁定，不可以凭示例代替用户决定。
3. **“审理后事实是什么”与“怎样执行”需分层**：A 不等于必然已更正；新证据重开不等于第四种结果；未受理不等于 D；权利变化或资格撤销本就不必硬塞进三种事实结果。这些由已确认治理和来源规则提供依据。
4. **无新第四类必要性证据**：在上述 14 个假设情景里，没有出现必须新增“文化争议裁定”“违规结案”或“权利失效型知识结案”的缺口。但这不是对全部未来案例和最终分类数的无条件证明。

## 4. Outcome（核查结论）

- **14 / 14 假设情景**都能在原有**范围分流 + A/C/D 候选事实结果 + 独立认可／安全／权利流程**的结构下获得不自相矛盾的处理路径；其中 #09 提示 V2 应明确“多主张分别结论”。
- **最小文档修订**：只在 V2 的结果适用段补充“不同可核实事实主张可分别取得不同结果，案件不是一个必须唯一的事实分数”，并注明这不意味着新增一种正式流程或额外分类。
- **不建议**：设定新证据门槛数字、强制人工审核等级、纠错权扩张、公众“争议”徽章、全站事实认证、额外结案类别或新处罚。
- **尚待用户明确确认（且只针对未批准部分）**：是否在第十四轮正式采用 A/C/D **三个候选知识事实结果**，以上述范围和非互斥主张方式作为阶段性产品规则；C/D 的具体执行阈值、人员、界面、时限可以继续暂缓。
