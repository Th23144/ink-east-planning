## 1. Naming boundary（名称边界：已淘汰“权威内容”）

**Work Recognition（作品认可）** 是正式机制名称；相应状态可称 **Recognized Work（正式认可作品／高认可作品）**。用户提醒使用过“权威作品／高价值作品”，随后接受纠正：**Authoritative Content（权威内容）** 已在第三轮淘汰，因为被认可的作品并不因此成为所有事实与文化解释的权威真理。

**Recognition Board（高认可内容板块）** 是原有内部中性工作标签，未来公开板块名称仍待决定。本文件不创造新的公众名称，也不恢复“权威内容”的权威背书语义。

## 2. Stage-specific scope（不同作品阶段的适用范围）

| Work position（作品位置） | Special interim Recognition protection（正式认可特殊临时保护） | Preserved existing authority（继续遵守） |
|---|---|---|
| **Normal / Community（普通社区／普通发表）** | **不适用**：不会仅因被质疑就进入 Candidate/Recognition 等级审查、强制自证亲历、暂停普通发表或自动限制常规发现 | 作者修改、正常反驳／讨论、全站基础安全和与实际风险相称的独立治理仍适用 |
| **Nomination Eligible / Nomination Exposure / Formal Nomination（可推举／推举曝光／正式推举）** | **不因推举而适用完整特殊机制**：提名只是评价机会，不构成 Candidate 或 Recognized | 可以按第三轮已有标准处理提名证据有效性、协调操纵等，但不得把提名当成已正式认可 |
| **Candidate（正式候选作品）** | **适用与正式评审相称的临时保护边界**：已独立核实的重大疑点涉及关键评审依据且继续相应评审／展示存在实际风险时，可在既有治理程序中考虑有限、可撤销的受影响评审步骤调整 | 不因举报自动撤销 Candidate、删除原文或惩罚作者；原公开候选评审及 Governance Review 规则继续有效 |
| **Recognized Work（正式认可作品）** | **重点适用**：经独立核实的重大关键事实／完整性疑点且继续特定官方主动背书或重点推广存在可说明的实际风险时，才能考虑有限临时调整 | 不把临时保护当成已经证实造假、正式撤销认可或处罚；涉及认可状态变更仍需其独立的正式复核决定 |

**Core distinction（核心区别）:** Nomination（推举）、Candidate（候选）、Recognized（认可）是第三轮既有真实阶段，不是基于举报新建的三级惩罚梯子；临时措施也不自动成为新的公开质量状态／标签。

## 3. Independent editorial curation responsibility（非认可作品的独立编辑责任）

一件 Normal Work（普通作品）即使没有进入 Candidate／Recognized，也可能被编辑放入特定**官方编辑精选、专题主动推广或 Issue（议题／期刊）策展**。用户确认：

- **Editorial Selection / Issue Inclusion（编辑选稿／议题收录） != Work Recognition（作品认可）**。获得官方编辑展示不令该作品自动进入正式认可审查，不增加对全体普通作者的系统性事实核验负担。
- 如有**独立核实且重要的风险**，平台可以就**自己作出的特定、当前仍在进行的官方编辑精选／主动背书行为**，考虑有依据、狭窄、可复核、可撤销的调整；不是对作者作品本身或个人资格作全局处罚。
- **单纯的常规算法推荐、热门、搜索出现、阅读量高、被编辑提及**不等于正式 Work Recognition 或必然触发这里的“官方主动精选责任”。普通社区不因曝光增加而获得正式评审义务。
- 第十一轮 Issue 历史快照、当时真实的收录决策与底层 Work 作者权利继续受版本／溯源规则保护：可合理修正**当前**有风险的官方精选展示，但不能暗中将历史议题改写为“从未收录”或用选择变化给作者贴上造假标签。
- 若存在独立的现实安全、权利或违法问题，依法及依全站现有治理规则处理；不需要强行进入 Work Recognition 程序，也不因本文件成立一套新型独立编辑处罚系统。

**This path is editorial/distribution responsibility only（这条路径仅处理编辑／分发责任）**，而不是将非认可作品扩展为 Candidate、Recognized 或来源权威记录。

## 4. Report is not evidence（举报与证据核验：已确认方案 B 的防滥用约束）

- 举报本身**只是输入线索**，不能自动引起对作品的公开负面标签、认可状态变更、暂停重点推荐或处罚。举报数量、账号数量、举报人身份、机构头衔、名气或付费身份均不替代事实证据。
- 对截图、影像、聊天记录、AI 可编辑材料或多个所谓独立来源，核验其真实性、来源关联、上下文及是否相互独立；**多账号重复提交同一伪造源头不能累加成独立证据**。任何工具或检测结论不能被当作无误的唯一真相。
- 必须区分**善意但错误的举报**与有充分证据证明的**故意伪造、协同骚扰和恶意操纵治理系统**；后者仅在独立符合行为违规标准时进入 Safety / Conduct Moderation（安全／行为审核）程序。
- 被举报作者不能仅因没有机票、护照、酒店凭证或不愿公开敏感隐私就自动被判定造假；正式认可中与关键亲历声明直接相关的合理核查应服从该正式评审的特定适用范围，不扩张成全站实名与全面自证要求。
- 即使素材看似可信，仍要区分**材料已被举报人提交**与**平台已经取得独立足够支持的重要疑点**；“收到严重举报”本身不能暂停推广。

## 5. Provisional scope, time limits and reversibility（临时措施的边界、期限与恢复）

- 方案 B 的门槛：经独立核实的**重要、与受影响评价／主动背书直接相关的实质疑点**，并有足够理由说明继续给出某项官方主动推广／背书存在**现实、可解释的风险**。**事实未查清不等于已经认定违规**。
- **Narrowest effective scope（最窄有效范围）**：优先仅调整必要的当前推广／受影响正式评审环节。不能因为某作品受质疑就自动删除普通发表、封禁账号、清除其所有作品；正式认可状态的撤销须走独立复核。
- **期限边界**：调查时间与临时限制时间不同。实施临时措施须有复核期限；调查尚未结束不能单独构成续期理由；重复举报不重置期限。只有独立证据仍支持重大风险且重新说明继续限制的必要性，才可考虑合理、受审查的有限延期；不能无限期以等待调查为由维持限制。**具体天数和人员分工未决定**。
- **误伤恢复**：若限制依据被否定、证据系伪造或继续限制已无足够理由，应撤销不必要措施，恢复原有有效认可／相关官方推广资格，并修正必要的当前标签、搜索／展示／缓存关联状态。重要错误处理遵守已有申诉、适当独立复核与真实恢复原则。
- **曝光责任**：**恢复本应具有的资格**不等于保证自然流量、阅读量或排名。若确实存在能够核实、原先安排但因错误限制被取消的官方精选档期，可以**考虑恢复相应展示机会**；不自动授予补偿流量、不承诺无法核算的自然曝光。
- 保留必要的内部决策／纠正溯源；公开信息以真实、适度、非污名化为原则，不能在尚未确认时展示“涉嫌造假”作为既定事实。

## 6. Explicit non-decisions（本次没有新增或批准的事项）

- 没有固定临时限制天数、延期次数或必须采用的单一工作流、统一人力配比；
- 没有确立新公开“涉嫌造假／正在调查”徽章、全站争议评分、统一对举报人的惩罚阶梯；
- 没有改变第三轮既有 Normal → Candidate → Recognized 核心状态机，也没有规定推举即承受完整正式复审；
- 没有授权强制所有普通社区内容学术核验，或将算法推荐／一般编辑链接视为正式认可；
- 没有要求作者普遍实名、提交旅行票据或放弃回应权；
- 没有认定“平台拥有无限期扣留曝光的权力”，也没有保证额外流量补偿／现金赔偿；
- 尚需后续讨论／实施的：重大实质疑点的具体证明标准、复核时限、人员独立性配置、具体编辑调整动作、申诉交互与下游数据恢复技术。

## 7. Resolution / precedence（当前结论与优先级）
