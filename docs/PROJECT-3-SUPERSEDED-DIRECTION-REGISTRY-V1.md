## 0. Core rule / 核心规则

Historical documents are preserved for Decision Provenance（决策溯源）. They are **not** automatically current product truth.

Before reusing any old rule, feature, page, tier, permission, paywall, ranking, identity or governance idea:

1. check `PROJECT-3-START-HERE.md`;
2. check this registry;
3. check the latest applicable Current Truth / Amendment / Seal record;
4. if an older plan conflicts, the later controlling record wins;
5. reviving a superseded direction requires an explicit new user decision.

Never infer “old file is more detailed, therefore old file is more authoritative.”
