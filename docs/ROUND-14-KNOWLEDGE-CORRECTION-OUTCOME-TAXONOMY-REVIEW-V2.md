## 1. 先判断是否属于正式纠错范围（已确认原则的复述）

- **普通社区 / 普通文化解读**：发表、不同意见、反驳、作者自愿修订，通常不构成正式知识纠错案件。对同一原典存在合理的不同诠释，即使各自引用文献，也不自动生成争议案件、公开争议标签或强制人工裁判。普通随笔和非重大错误不自动被学术核验。
- **实际承担来源／知识责任的内容**：原典版本、馆藏来源、转录、归属、可核实的关键事实以及平台承担责任的编辑记录，可按实际责任、证据、影响处理；重要且有实际依据的来源事实问题可以进入正式纠错。
- **正式 Candidate / Recognition（候选／作品认可）**：如有影响评审结果的关键事实或材料被证实存在问题，走作品／版本范围内的独立认可复核，不把它混成普通知识纠错结案，也不连坐作者其他作品。
- **Safety / Conduct（安全／行为）**：独立违规和伤害问题交由各自审核路径，不借“知识纠错”之名施加统一处罚。

**不受理为正式知识案件、改由讨论／轻量反馈处理**与**已经进入正式知识案件后的实质结案结果**不是同一个分类维度。此区分是对既有“程序状态 != 实质结论”和适用范围规则的整理，不等于新建全站强制受理程序。

**同一份请求可以涉及多个独立事实／Claim；事实结论按受到核查的具体主张分别记录，不要求整个案件只有一个互斥的 A/C/D 结果。** 例如某处引文确有错误，但另一项重要归属事实仍未确定，可分别对应候选 A 和 C。这是保留旧 V1 §3 已提出、并与 Round 7 Claim／重要变更规则一致的边界，不增加新类别或强制流程。

## 2. 仅在确实属于正式知识纠错范围时，以下三种作为候选结果（不是最终批准的分类数）

### A. Confirmed Error（确认可核实错误）

相关日期、底本、版本、转录、引用、来源或归属等**可核查事实确有错误**。

- 由有相应责任与权限的一方纠正其负责的记录；保护来源底本、异文与修订证据链。
- 独立作者有回应／修订机会；平台不能偷偷改写他的正文或主观观点。必要时可以在适当范围内作有证据的事实说明。
- 重要修订需要合理留痕，轻微错字不用普遍显著公告。

**“确认错误”是事实判断，“已完成更正”是后续执行状态，不应自动混写成一个结果。**

### C. Material Source/Factual Claim Undetermined（重要来源／事实主张暂无法确定）

**已经进入适用范围的**重要来源记录、归属或可核查事实确有实质待核之处，但现有证据不足以可靠判定；或可靠材料之间仍留有无法消除的来源事实不确定性。

- 不制造确定答案，不因有争议就处罚作者、否定思想观点或取消作品认可。
- 按实际平台责任和下游依赖程度，可在平台维护的相关记录上保留恰当的不确定性说明或证据来源，不普遍给普通作品贴“有争议”标签。
- 新的重要证据、情况变化或实质程序错误可依既有复核原则重新处理。

**此类不等于“双方的文化解释都很有道理，因此平台必须开一个争议案件”。**

### D. Correction Request Not Sustained（纠错请求不成立）

针对实际可审查事实的指控，在其应适用的审查范围内没有得到充分依据支持，且并无必须由平台以未定状态维护的重要来源事实问题。

- 不因一项未经证实的质疑更改原记录或给作品附加污名化标记。
- 可在适当情况下向提出者说明不采纳理由。
- “本次纠错请求未得到支持”**不等于**“原作品所有主张均已被平台证明为真”。

**与 C 的边界：** C 是重要来源／事实本身仍存在需要如实承认的不确定性；D 是本次纠错主张不能成立，且没有依据将有关记录转为“重要事实未定”。两者不能单凭“提供材料少”机械区分。此处是为了排除原 V1 两类重叠而提出的工作表述，**精确判断阈值未锁定**。

## 3. 原 V1 的 B、E 不作为同一知识结果清单中的独立类别

**旧 B — Supported Dispute（确认有依据的解释争议）**：
- 不再把“对同一古籍存在两种有来源支持的解读”当作正式纠错案件的自动结案结果。
- 对**确有重要来源／归属事实不确定性**的记录，仍可依现有来源规则维护有依据的不同见证、版本和不确定性；必要时参照上面 C 的候选处理，而不裁决哲学理解的唯一真理。
- 不能借此删除第七轮允许多种 Claims（主张）长期并存、或合理注明来源背景的既有能力；只是取消“思想分歧必须结案”这一错误适用。

**旧 E — Independently Established Misconduct（经独立程序认定违规）**：
- 根据已确认的四条治理路径，属于 Safety / Conduct Moderation（安全／行为审核）而不是知识事实结案结果。
- 如另行涉及 Recognition（作品认可）、Contributor Qualification（贡献者资格）、身份或能力，必须按各自独立标准判断；不因一次引用错误或举报自动处罚、撤销或连坐。
- 可与同一事件的知识纠错并行，但分别记录决定和影响。

## 4. 原有工作流程与展示原则不变

- 继续按已确认的 **Propose → Triage → Evaluate → Resolve → Record → Revisit（提出→分流→评估→处理→留痕→复核）** 原则行事；Received / Under Review / Closed / Reopened（已受理／审查中／已结案／重新开启）是流程状态而非事实真假结论。
- 对确属适用范围的重要案件，纠错建议、编辑权、纠错决定权、作品认可权分离；作者有适当回应机会，但不能无限否决平台负责记录的证据支持修订。
- 对重要平台记录保留可解释的历史与必要的作者／来源归属；对敏感证据保护隐私。高影响处理沿用已确认的独立复核、合理申诉、纠正恢复框架。
- 不以会员、名气、编辑收录、热度或普通用户身份自动改变审查结论。纠错、认可资格与推荐当前展示状态遵守现有跨轮修订。
