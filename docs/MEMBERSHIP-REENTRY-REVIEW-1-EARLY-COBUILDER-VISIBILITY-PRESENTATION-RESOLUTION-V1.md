## 1. Private-first historical view（以个人私有视图为主）

A user's fuller Early Co-builder（早期共建者） history should primarily live in a private personal history view.

Possible contents:
- complete early co-building timeline（完整早期共建时间线）;
- support history（支持历史）;
- product-testing / feedback history（产品测试 / 反馈历史）;
- project / recovery participation（项目 / 寻回参与）;
- evidence / provenance explanation（证据 / 来源说明）.

## 2. Public acknowledgment is optional（公开历史致谢可选）

Historical recognition may exist even if the user chooses not to display it publicly.

Public-facing examples may include:
- Early Participant（早期参与者）;
- Founding-stage Co-builder（创始阶段共建者）;
- selected milestone / project acknowledgment（部分里程碑 / 项目致谢）.

Public display must explain historical context and must not imply expertise, authority or superiority（专业性、权威性或高人一等）.

## 3. Sensitive evidence remains internal（敏感证据继续内部保存）

Sensitive records remain internal or access-limited even when the related history is publicly acknowledged.

Examples:
- exact financial support amounts（具体资金支持金额）;
- private security / bug reports（私密安全 / 问题报告）;
- sensitive project evidence（敏感项目证据）;
- private identity/contact records（私密身份 / 联系记录）;
- internal verification/moderation context（内部验证 / 审核上下文）.

## 4. Full context belongs on profile/detail surfaces（完整上下文主要放资料 / 详情页）

Avoid Badge Stack（徽章堆叠） across feeds/content cards.

Use:
- profile/detail surfaces（个人资料 / 详情页） for fuller history;
- contextually relevant markers（与上下文相关的标识） only where needed in feeds/content cards.

## 5. “Spiritual Shareholder（精神股东）” remains optional community language（继续作为可选社区语言）

“Spiritual Shareholder（精神股东）” may remain an optional public/community expression.

The underlying architecture and historical truth remain the typed Early Co-builder（早期共建者） records, not the slogan itself.
