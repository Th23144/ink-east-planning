## 1. Author right after Recognition（认可后作者的自愿退出权）

1. 即使某作品已经通过平台正式评审获得 **Recognized Work（正式认可作品）** 身份，作者仍可以**主动要求终止该作品当前的正式认可展示／参与**；之前的同意不等于必须永久接受当前正式认可呈现。
2. 生效之后，不应继续把该作品作为**当前正在享有、由作者继续参与的正式认可作品**显示在有关认可标识、当前认可作品专区、以现行认可状态为前提的官方认可推广之中。当前可见状态应与自愿退出相符；普通搜索和自然阅读无需因此消失。
3. 自愿退出**不是** `Not Recognized（评审不通过）`、`Recognition Invalidated（关键证据失效）`、`Misconduct Sanction（违规处罚）` 或官方认定作品“原本没有质量”。不得以这些结果名义呈现或推断作者不可信。
4. 作者不因此自动丧失该作品的**普通发表、社区互动、正常自然发现**，也不连坐其他作品、账户资格或作者身份；已有独立的编辑精选、期刊历史收录也不会因为取消当前 Work Recognition 展示而被秘密擦除。
5. **历史授予事实必须准确保留**：确曾在某个时间／作品版本获得正式认可，之后作者主动结束当前认可展示。历史记录与当时的评审及版本证据，按照审计、隐私、法律和必要性范围保存。历史页面若显示当时状态，应能与当前状态区别；不能假装从未认可，也不能继续暗示如今仍有效参与认可。
6. 自愿退出**不阻止独立且正当存在的治理义务**：已经存在或随后发现的来源事实纠错、必要的作品认可完整性复核、行为／安全及合法性问题，仍依据各自权限和证据处理。退出本身不是违规证据；但也不能作为消除事实或责任的工具。

## 2. Critical status distinctions（必须明确区分的不同结果）

| Situation（情形） | Product meaning（产品含义） |
|---|---|
| `Author Voluntary Recognition Withdrawal（作者自愿退出当前认可展示）` | 作者停止当前认可展示／参与，不推断质量或诚信错误；历史曾获认可仍为真实记录 |
| `Recognition Invalidated After Revalidation（复核后认可依据失效）` | 经独立事实／完整性程序证明影响认可的关键依据已不再成立；不能伪装为作者主动退出 |
| `Recognized Prior Version / Revalidation of New Version（旧版曾获认可／新版需复核）` | 属于第三轮既有版本感知规则，不因作者退出而混成同一个结果 |
| `Editorial Selection / Issue Inclusion（编辑精选／期刊收录）` | 独立编辑决策，不因作者退出作品认可而自动撤销；历史与当前展示仍须真实 |

上表是**结果原因／状态含义的区分**，不是新建四个内容等级，也不重新设计第三轮 `Normal → Candidate → Recognized` 核心状态机。

## 3. Recognition opt-in/out scope now resolved（三段作者选择权已完成原则性确认）

- **推举之后、进入 Candidate 之前**：须取得作者明确参与同意；他人推举本身不要求作者预先同意。
- **已经进入 Candidate、正式评审正在进行**：作者可以主动退出，不能把自愿退出记为负面评审结果。
- **已经获得 Recognized Work**：作者可以终止当前正式认可展示／参与，既有真实历史授予事实保留，不等于撤销当时的评审或官方处罚。

此处不对每个普通社区作品建立强制评审、身份核验或额外治理负担，不推翻恶意举报防护。
