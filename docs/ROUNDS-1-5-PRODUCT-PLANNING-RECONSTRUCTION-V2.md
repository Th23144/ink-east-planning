# 1. Long-term platform product picture / 长期平台产品图景

The product was reframed during Rounds 1–5 away from a narrow ancient-text site.

The accepted direction is a broader platform combining:

- knowledge / cultural context;
- reading and publishing;
- community interaction;
- discovery/recommendation;
- structured Topic / Place / Knowledge relationships;
- high-quality work recognition;
- identity/contributor systems;
- future Membership and services;
- eventually broader cultural, travel/local, practical and non-China-only subject areas.

Key product principle from the early scope correction:

> social-platform-like in scale/interaction potential, but with stronger structure, provenance, knowledge/context and real-world usefulness than a generic social feed.

Eastern/Chinese culture remains the initial wedge, not the permanent platform boundary.

# 2. User-facing product surfaces actually planned in Rounds 1–5 / 第一至第五轮真实规划过的用户界面与产品面

## 2.1 Home / For You（首页 / 为你推荐） — confirmed product requirement

Round 3 explicitly required a cross-domain default discovery surface.

Product intent:

- user does not need to choose a Domain / Topic / Place before seeing value;
- eligible content from multiple parts of the platform can appear in one mixed discovery surface;
- it is ranked/recommended, not literally random;
- it should include exploration/serendipity to reduce filter-bubble collapse;
- it is a projection over the same underlying content graph, not a duplicate content system.

Later Round 10 revalidated and deepened this subject.

**Status: POST-RESET CONFIRMED（重构后已确认）.**

---

## 2.2 Scoped discovery views（范围化发现视图） — confirmed

- Domain（领域）;
- Topic（主题）;
- Place（地点）;
- Following（关注）;
- future context-specific projections.

These coexist with the global mixed discovery surface.

**Status: POST-RESET CONFIRMED.**

## 2.3 Canonical Classical Text Reader / Research Surface（古籍原典阅读 / 研究界面） — revalidated lane

The post-reset Content / Knowledge plan explicitly preserved a dedicated classical-text reading/research lane.

Product characteristics:

- canonical work / chapter / passage reading;
- source / edition / provenance integrity;
- clean reading surface;
- no ordinary social thread directly polluting the canonical record;
- related interpretation/discussion linked through companion objects;
- future citation, saved passage and private-note capabilities may reference the canonical text without altering it.

Shidianguji（识典古籍） remains a functional reference for this lane only.

**Status: LEGACY-INSPIRED BUT POST-RESET REVALIDATED（受旧方案启发但已在重构后重新确认）.**

## 2.7 Recognition Candidate Review Surface（候选评议面） — explicitly designed

Rounds 2–3 planned a visible product destination for formal work evaluation.

The final early product model is not two parallel review boards.

Product intent:

- ordinary work remains in normal surfaces;
- eligible work may receive fair semi-blind nomination exposure;
- after sufficient valid evidence, the same Work becomes Candidate（候选作品）;
- Candidate is publicly observable in the Candidate Review Surface（候选评议面）;
- structured review occurs there;
- Candidate remains the same underlying Work, not a duplicated article.

**Status: POST-RESET CONFIRMED.**

# 3. Reading experience actually planned / 真正规划过的阅读体验

The user's recollection that Rounds 1–5 already contained “where/how users read” is supported.

The post-reset product contains a **distributed reading experience**, not one confirmed Reading Room container.

## Confirmed/planned reading components

### R1 — Public content reading
Users read:

- canonical/source-backed works;
- editorial/teaching works;
- contributor works;
- community/user works;
- future travel/local/practical content.

### R2 — Related reading
The Knowledge/Content plan explicitly anticipates related reading among works, topics and source objects.

### R3 — Save / Bookmark（收藏 / 书签）
Save exists as a platform primitive and durable reading-intent relation.

### R4 — Follow（关注）
Users may follow relevant authors/topics/places/future supported entities.

### R5 — Reading History（阅读历史）
Reading history exists as a behavioral/state concept and later feeds the Interest Graph only under separate privacy/semantics rules.

### R6 — Private Notes / Saved Passages（私人笔记 / 保存段落）
The Content/Knowledge plan explicitly leaves room for future private reader notes and saved passages linked to canonical material without changing the canonical record.

### R7 — Topic / Place / Text / Work navigation
Reading/discovery is structurally connected to Topic / Place / Text / Work relations rather than one flat article archive.

### R8 — Home / For You + scoped views
Users can discover content broadly or enter scoped contexts.

## Critical conclusion

These are real reading-product needs.

They do **not** prove that the platform requires a separate page/module/product named Reading Room（阅读室）.

# 7. Membership — what was and was not actually planned / 会员当时到底规划到了哪里

## Actually confirmed

Rounds 1–5 repeatedly confirm:

- Membership/VIP exists as a future product/business subject;
- payment may provide legitimate product benefits;
- it may reduce selected zero-cost/Sybil friction;
- expanded capability may be considered where economically/risk justified;
- payment cannot create professional qualification, Work Recognition, Reviewer Trust, Governance Authority or organic reach;
- exact bundle must later be benchmarked and designed for this product.

Round 5D even listed broad **reference categories** that could be studied later:

- publishing limits;
- quality-of-life tools;
- customization;
- saved/archive-related capabilities;
- creator tools;
- member-only surfaces;
- support/priority access.

These are benchmark categories, **not accepted benefits**.

## Not confirmed

Rounds 1–5 did **not** confirm:

- Reading Room as a required product;
- VIP Library;
- paid article/Issue/Archive access;
- Reader/Patron plan structure;
- fixed prices;
- member-only Reader Notes;
- Patron governance votes;
- exact member workspace;
- exact supporter identity;
- exact service discounts/credits.

# 9. Product journeys reconstructed from Rounds 1–5 / 从第一至第五轮重建出的用户路径

## Journey A — Reader / discovery
```text
Open platform
→ Home / For You or scoped Topic / Place / Following
→ read canonical / editorial / contributor / community content
→ follow related context / related reading
→ Save / Follow where useful
→ possibly discuss / publish / return later
```

## Journey B — Community participant
```text
Register
→ ordinary Community participation under proportionate anti-abuse controls
→ publish / reply / discuss
→ build durable contribution history
→ strong Work may receive fair Recognition opportunity
```

## Journey C — High-quality Work
```text
ordinary public Work
→ nomination eligibility
→ fair semi-blind nomination exposure
→ Candidate
→ public Candidate Review Surface
→ Recognized / revision / governance outcome
```

## Journey D — Contributor
```text
ordinary or externally established user
→ application / invitation / legitimate onboarding
→ scoped evidence review
→ Contributor Qualification + Expertise Scope
→ richer profile/tooling/opportunities
```

Qualification does not guarantee work quality or ranking.

## Journey E — Future Membership
```text
ordinary platform use remains viable
→ optional paid relationship/product benefits
→ exact benefits deferred
```

No Reading Room container is implied by this journey.
