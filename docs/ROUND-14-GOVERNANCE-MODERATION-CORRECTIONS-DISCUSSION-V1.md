## 1. Round purpose（本轮目的）

Ink & East（墨与东方） already separates:
- Canonical / Source-backed（规范 / 来源型）;
- Editorial / Teaching（编辑 / 教学）;
- Contributor（贡献者）;
- Community / User（社区 / 用户）;
- Candidate Review（候选审查）;
- Recognized Works（认可作品）;
- Open Cultural Recovery（开放文化寻回）.

Round 14（第十四轮） must define how the platform handles:
- harmful or rule-breaking behavior（有害 / 违规行为）;
- factual/source disputes（事实 / 来源争议）;
- corrections and revisions（纠错 / 修订）;
- appeals（申诉）;
- reversals/restoration（撤销 / 恢复）;
- role-specific accountability（按角色区分的责任）.

The goal is **not** to create one giant “platform governance score（平台治理分）”.

---

## 2. First architectural separation（第一层架构分离）

The platform should distinguish at least four different questions:

### A — Safety / Conduct Moderation（安全 / 行为审核）
Question:
> Does this behavior/content violate platform rules or create safety/abuse problems?（该行为 / 内容是否违反平台规则或造成安全 / 滥用问题？）

Possible actions:
- remove/restrict content（删除 / 限制内容）;
- restrict behavior/capability（限制行为 / 能力）;
- temporary suspension（临时停用）;
- account-level action where justified（必要时账户级处理）.

### B — Factual / Source Correction（事实 / 来源纠错）
Question:
> Is a factual, provenance or citation claim wrong, incomplete, contested or outdated?（事实、来源溯源或引用主张是否错误、不完整、有争议或已过时？）

Possible actions:
- correction note（纠错说明）;
- source replacement/addition（替换 / 增补来源）;
- version update（版本更新）;
- contested-status annotation（争议状态说明）.

This is not automatically a moderation punishment.

### C — Quality / Recognition Review（质量 / 认可审查）
Question:
> Does a work still meet the independent standards for Candidate Review / Recognized Works（候选审查 / 认可作品）?（作品是否仍满足独立的候选审查 / 认可标准？）

Possible actions:
- maintain status（维持状态）;
- revise evaluation（修订评价）;
- withdraw Recognition（撤回认可） where independently justified.

This must remain separate from payment, Membership（会员）, popularity and ordinary moderation.

### D — Identity / Qualification / Capability Review（身份 / 资格 / 能力审查）
Question:
> Does a person or organization still meet the requirements for a particular verified identity, qualification or capability?（个人或组织是否仍满足某个已验证身份、资格或能力要求？）

Examples:
- Contributor Qualification（贡献者资格）;
- Organization / Claim Verification（组织 / 权属验证）;
- specific publishing/review capabilities（特定发布 / 审查能力）.

This is not a universal trust rank.

---

## 3. Correction should not equal punishment（纠错不等于惩罚）

A healthy knowledge platform must allow honest error correction without making every correction look like misconduct.

Therefore:
- factual correction（事实纠错） can occur without account punishment;
- source updates（来源更新） can occur without lowering identity status;
- revisions（修订） can be part of normal knowledge maintenance;
- malicious fabrication / repeated deceptive behavior（恶意伪造 / 持续欺骗行为） may separately trigger Conduct Moderation（行为审核）.

---

## 4. Versioned history and explainability（版本历史与可解释性）

For important public knowledge/editorial records, the platform should prefer explainable change history where appropriate:
- what changed（改了什么）;
- when it changed（何时修改）;
- why it changed（为什么修改）;
- source/evidence basis（来源 / 证据依据）;
- whether the change was author, editor, reviewer or platform initiated（修改由作者、编辑、审查者还是平台发起）.

Exact UX（用户体验） remains later.

---

## 5. Appeals and reversibility（申诉与可逆性）

High-impact platform decisions should not be treated as irreversible black boxes by default.

Potential principle:
> **The higher the impact of an action, the stronger the need for reason, provenance, appeal and reversibility where feasible.（处理影响越大，越需要明确理由、来源记录、申诉机制，以及在可行时支持恢复。）**

Possible high-impact cases:
- account suspension（账户停用）;
- Contributor Qualification（贡献者资格） removal;
- Organization verification（组织验证） removal;
- Recognition（认可） withdrawal;
- major content removal（重大内容删除）.

---

## 6. No universal punishment ladder by identity（不建立按身份统一处罚阶梯）

The platform should avoid:
- one global Trust Score（统一信任分）;
- one universal strike count controlling every domain（统一违规次数控制所有领域）;
- paid/Membership status affecting moderation outcomes（付费 / 会员状态影响审核结果）;
- Early Co-builder（早期共建者） history shielding users from enforcement;
- popularity protecting a user from correction or moderation.

Actions should be scoped to the relevant behavior, capability, content or role whenever possible.

---

## 7. First decision set（第一组决策题）

1. Should Safety / Conduct Moderation（安全 / 行为审核）, Factual / Source Correction（事实 / 来源纠错）, Quality / Recognition Review（质量 / 认可审查）, and Identity / Qualification / Capability Review（身份 / 资格 / 能力审查） be formally separated?
2. Should ordinary factual correction/revision be treated as normal knowledge maintenance rather than punishment?
3. Should important public knowledge changes preserve explainable version history where appropriate?
4. Should higher-impact decisions require stronger reasons, provenance, appeal and possible reversibility?
5. Should enforcement remain scoped to the relevant content/behavior/capability instead of creating one universal punishment/trust ladder?
