# 第十二轮工作坊 B——取代关系回归闸

> **Scope:** Membership Value Proposition & Benefit Catalogue（会员价值主张与权益清单）

## 0. Gate result / 闸门结论

Workshop B may open only under the corrected Round 12 baseline.

The old detailed Membership model is **not inherited**.

The following current-vs-superseded comparison controls the workshop.

---

# 1. CURRENT / 当前控制方向

## C1 — Published content is public / 已发布内容公开

Normal published knowledge, editorial, community, Issue（议题） and Archive（归档） content remains publicly readable when otherwise legally/policy eligible.

Membership（会员） is not a content-unlock mechanism.

## C2 — Membership sells relationship and scarce value / 会员售卖关系与稀缺价值

Candidate value dimensions may include:

- Supporter Relationship（支持者关系）;
- Participation Capacity（参与容量）;
- Reading Room Workspace / Tools（阅读室工作空间 / 工具）;
- Editorial / Community Experience（编辑 / 社区体验）;
- Scarce Service Courtesy / Priority（稀缺服务礼遇 / 优先）;
- bounded Capability Acceleration（有边界的能力加速）;
- other legitimate non-authority benefits.

These are design dimensions, not already-approved benefits.

## C3 — Basic public/account functions cannot be artificially paywalled / 基础公开与账户功能不能为造会员价值而强行收费

Ordinary public reading and basic account/community functions must be evaluated on their own product merits.

The platform must not deliberately cripple the free experience merely so Membership appears valuable.

## C4 — Membership cannot buy authority / 会员不能购买权威

Payment cannot create:

- Contributor Qualification（贡献者资格）;
- Work Recognition（作品认可）;
- Reviewer Trust（评审信任）;
- Formal Nomination（正式推举）;
- Governance Authority（治理权力）;
- organic Recommendation（自然推荐） privilege;
- factual/source authority.

## C5 — Services remain separate products / 服务保持独立产品

Custom Reading（定制解读）, Custom Ebook Studio（定制电子书工作室） and future scarce services remain separately purchasable unless later explicitly changed.

Membership may later offer courtesy/priority/allowance/booking benefits if economically justified, but does not redefine the service itself.

## C6 — Community remains one system / 社区仍是一个系统

Round 8's unified Community System（统一社区系统） remains controlling.

Membership must not silently create a second disconnected VIP Forum（会员论坛） as a parallel social platform.

## C7 — Capability acceleration is bounded / 能力加速有边界

Payment/economic friction may reduce selected anti-Sybil / anti-abuse friction for certain product capabilities.

It cannot manufacture history, competence, reviewer/governance evidence or ranking privilege.

## C8 — Packaging comes later / 包装后置

One tier / two tiers / multiple plans, plan names, pricing and billing cadence are not Workshop B decisions.

Workshop B must first define value and benefits.

---

# 2. SUPERSEDED / 已淘汰方向

The following must not be used as Workshop B defaults:

1. 30% Paywall（30% 付费墙）;
2. VIP Library（会员内容库） as a required paid-content lane;
3. VIP Long Read（会员长文） as a paid editorial ontology;
4. “99% free + rare VIP articles” as current truth;
5. Article / Issue / Archive Membership gating;
6. fixed Reader / Patron（读者 / 赞助者） tier names;
7. historical fixed prices such as old USD/CNY examples;
8. Reader Notes（读者札记） automatically being member-only merely because an old preview said so;
9. Patron Vote（赞助者投票） as purchased governance power;
10. Custom Reading（定制解读） requiring Membership;
11. VIP status as professional/identity evidence;
12. Membership buying organic reach;
13. old Workshop A A1–A50 as automatically current;
14. old Workshop A Adversarial Audit（对抗性审计） as proof that the corrected Membership model is valid;
15. old WordPress / Level 1 `reader` / `patron` / `is_vip` fields as product requirements.

---

# 3. PROVENANCE-ONLY / 仅用于决策溯源

The following old ideas may be studied as historical product inspiration, but carry zero automatic decision authority:

- supporter-style Membership language;
- Reading Room（阅读室） as a calm member relationship surface;
- editorial letters / reply priority;
- member event ideas;
- annual physical publication ideas;
- service priority / courtesy;
- contribution/publishing-capability ideas;
- optional supporter identity display;
- editorial feedback / preference expression.

Each must be re-evaluated against the current platform architecture, operational cost and free-user baseline.

---

# 4. UNRESOLVED / 当前真正未决定

Workshop B is allowed to discuss, but not silently decide:

1. What is the primary reason a user pays when all published content is already public?
2. Is Supporter Relationship（支持者关系） itself sufficient as one major value pillar?
3. What benefits are real scarce value vs artificial restriction?
4. Which reading/workspace conveniences should be free account basics?
5. Which deeper Reading Room（阅读室） functions could legitimately belong to Membership?
6. Which additional participation capacities are acceptable?
7. Should Membership include limited-capacity editorial/community experiences?
8. Should any member-only small-group space exist inside the unified Community System?
9. Should members receive non-binding editorial preference/feedback opportunities?
10. Which service benefits, if any, are economically sustainable?
11. Which capability accelerations are justified by anti-abuse economics?
12. Should there be physical/annual artifacts or supporter acknowledgements?
13. Which benefits create recurring value rather than one-time novelty?
14. Which benefits create excessive operational burden?
15. Which benefits risk turning payment into status hierarchy?
16. Which benefits should be rejected because they should simply be free platform functionality?

---

# 5. Gate decision / 闸门决定

**PASS.**

The Membership Value Proposition & Benefit Catalogue（会员价值主张与权益清单） workshop may proceed.

Mandatory rule for Workshop B:

> **Do not ask “what can we lock behind Membership?”  
> Ask “what additional relationship, scarce capacity, experience, tooling or service value is genuinely worth paying for when the knowledge itself remains open?”**

No product benefit, tier, price or implementation is authorized by this gate.
