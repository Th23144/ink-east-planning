## 1. Purpose（目的）

The relationship foundation is now clear:
- independent products/projects（独立产品 / 项目）;
- Standing Strategic Relationship（持续战略关系）;
- Preferred Strategic Partner（优先战略合作伙伴）, non-exclusive（非排他）;
- no platform privilege（无平台特权）;
- normal attributable cross-product references（正常、可归因的跨产品引用）;
- personal-data independence（个人数据独立）;
- hard editorial/source/recognition/governance boundaries（编辑 / 来源 / 认可 / 治理硬边界）;
- editorial integrity without assuming structural conflict（保持编辑完整性，但不预设结构性冲突）.

The next task is to define **what kinds of cooperation actually belong in the relationship**.

## 2. Candidate cooperation families（候选合作类型）

These are discussion candidates（讨论候选）, not locked product commitments.

### C1 — Research Collaboration（研究合作）
Possible forms:
- joint investigation（联合调查）;
- material / craft research（材料 / 工艺研究）;
- field documentation（田野记录）;
- source tracing（资料追溯）;
- contemporary practice testing（当代实践测试）.

### C2 — Object / Material Practice Collaboration（物件 / 材料实践合作）
Possible forms:
- reconstruction / reproduction experiments（复原 / 再制作实验）;
- material testing（材料测试）;
- care / aging / durability observation（照护 / 老化 / 耐久观察）;
- use / space / configuration studies（使用 / 空间 / 配置研究）.

This does not imply every research object becomes a product.

### C3 — Knowledge ↔ Object Linking（知识 ↔ 物件关联）
Ink & East（墨与东方） knowledge objects may link to relevant Spatial Flow（空间流） objects/projects, and vice versa, when the relation is genuine and useful.

This is already confirmed as a normal capability; this discussion concerns scope and presentation, not existence.

### C4 — Content / Publication Collaboration（内容 / 发布合作）
Possible forms:
- co-authored or separately authored related works（联合署名或各自署名的关联作品）;
- interviews（访谈）;
- maker/workshop documentation（制作者 / 工坊记录）;
- project journals（项目记录）;
- explanatory companion works（解释性配套作品）.

Authorship / Publisher / Operator（作者 / 发布者 / 操作主体） remain attributable.

### C5 — Product / Commercial Collaboration（商品 / 商业合作）
Possible forms:
- jointly developed objects/products（联合开发物件 / 商品）;
- licensing（授权）;
- sourcing / supply collaboration（采购 / 供应合作）;
- limited project commerce（限定项目商业化）.

Each requires project-specific rights / ownership / commercial terms（逐项目权利 / 所有权 / 商业条款）.

### C6 — Exhibition / Event / Physical Experience（展览 / 活动 / 现实体验）
Possible forms:
- exhibitions（展览）;
- workshops（工作坊）;
- talks（讲座）;
- temporary installations（临时装置）;
- pop-up cultural / object experiences（快闪文化 / 物件体验）.

### C7 — Cultural Recovery Support（文化寻回支持）
Spatial Flow（空间流） may, where suitable, support a specific Open Cultural Recovery（开放文化寻回） case through material, craft, documentation, reproduction, logistics or other explicitly scoped capabilities.

Spatial Flow（空间流） is not the default or exclusive recovery operator（默认 / 唯一寻回执行方）.

### C8 — Referral / Discovery（引导 / 发现）
A user may move from one product to the other when the crossover is genuinely relevant.

This should remain contextual, explicit and non-forced rather than becoming a universal funnel（统一漏斗）.

---

## 3. Anti-collapse rule（防止关系塌缩规则）

No cooperation family above means:
- Ink & East（墨与东方） becomes Spatial Flow（空间流） marketing;
- Spatial Flow（空间流） becomes Ink & East（墨与东方）'s exclusive physical-world executor（唯一现实执行端）;
- every piece of knowledge needs a product;
- every product needs an Ink & East（墨与东方） article;
- every collaboration needs monetization;
- every platform user should be routed toward Spatial Flow（空间流）.
