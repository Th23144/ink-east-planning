## 1. User-approved narrow decision（本次确认的范围）

1. **不得绕过明确不同意且未授权的真实共同作者。** 对 A、B、C 共同完成的一件作品，如 A、B 同意进入正式 Candidate Review，而真实共同作者 C **明确拒绝**参加、并**没有有效授权他人代为表达此项参与同意**，则**整件共同作品不得直接进入 Candidate 正式评审**。必须先妥善解决该共同作者参与／权限问题；平台不能把多数同意、发起人身份、合作署名、普通投稿权限或者系统自动邀请，解释成 C 的同意。
2. **普通发表与推举不因此被否定。** 前项决定约束的是**整件共同作品首次正式进入 Candidate**，不是普通作品发表、普通可发现性、他人的推举记录或合法的独立编辑精选。C 的拒绝不自动等于作品低质、评审失败、违规，也不应因此处罚 A、B 或 C。
3. **已存在的有效代表授权与明确拒绝须区分。** 第六轮已有 Scope（作用范围）明确的权限与代表机制；作者本人作出同意与由实际具备相关有效授权的代表表达同意，在权限语义上可以区分于“发布者未获授权即代替他人同意”。**本次选择并未制定 Candidate 专用代理授权形式／必需人数／委托期限，也没有确认任何默认代理权。** 如果存在真正的授权／撤回／主体资格争议，须先按既有权限及争议原则核实，不能假定已获同意。
4. **不得误扩展到认可后的退出。** 本次仅对**尚未进入 Candidate 的共同作品首次准入**确定阻断条件。已在 Candidate 的个人退出、已 Recognized 的作者终止当前参与／展示，仍遵照此前三阶段自愿退出与共同作品整体权限规则：单独退出不自动撤销整件作品、关键权利及认可依据变化须独立复核。**不因这里的入池前拒绝，就倒推出每位共同作者在认可后永远拥有无条件一票否决权。**

## 2. Illustration and limits（具体案例与不得擅自推断）

| 场景 | 结果 |
|---|---|
| A、B 同意；真实共同作者 C 明确反对，未授予该事项的代理权 | **整件作品不能进入 Candidate；先解决 C 的参与问题**。但作品正常发表不因此自动受限 |
| A、B 同意；C 尚未回复，也没有可核实的有效授权 | **不能把沉默当成参与同意**。具体催告时限、流程如何结束，仍待设计 |
| A、B 同意；有人声称“C 已委托我决定”，但拿不出有效的限域授权 | 不能仅凭声称代表、投稿人或显示署名就认定 C 同意；先核实权限 |
| A、B、C 均作出有效参与选择，且其余正式候选资格条件满足 | 本次共同作者同意问题不再阻碍；**不自动保证 Candidate 资格或获 Recognized** |
| 作品已通过 Candidate 并获得 Recognized 后 C 决定退出当前个人参与 | 按已有**个人退出／合作作品整体权限**规则处理；不能将本次入池前不同意条款当成自动撤销整个认可的理由 |
