## Sealed durable boundaries / 已封存的长期边界

The seal preserves, among other things:
- one unified Community System（统一社区系统） across the platform;
- Community Publication（社区发布物）, Discussion Thread（讨论线程）, Question（问题）, Answer（回答） and Reply（回复） as distinguishable object classes;
- canonical/source-backed content remains separate from ordinary social discussion while allowing precise companion links;
- stable thread/message identity independent from URL, ranking and UI position;
- conversation structure != knowledge structure;
- social feedback != truth / source reliability / Work Recognition（作品认可）;
- author/creator != moderator by default;
- lifecycle state != truth or recognition;
- withdrawal / deletion / moderation removal / legal removal / privacy deletion remain distinct;
- Report（举报） != guilt;
- Moderation Case（审核案件） remains separate from ordinary content editing;
- moderation visibility != Recommendation ranking（推荐排序） != user preference;
- personal Block / Mute（屏蔽 / 静音） != platform-wide enforcement;
- community actions preserve Actor / Acting Context（行为主体 / 行为情境）;
- material mutable rules remain governed by the sealed Rule Evolvability & Change Architecture（规则可演进与变更架构）.
