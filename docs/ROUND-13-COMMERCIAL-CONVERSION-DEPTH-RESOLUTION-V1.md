# Round 13（第十三轮）— Commercial Conversion Depth Resolution V1
# 商业转化深度结论 V1

> **Status（状态）:** USER-CONFIRMED / RESOLVED（用户确认 / 已解决）
> **Implementation（实现）:** NOT AUTHORIZED（未授权）
> **Merge（合并）:** NOT AUTHORIZED（未授权）

## 1. Confirmed direction（已确认方向）

Ink & East（墨与东方） does not lock the whole platform to one commercial-conversion depth.

Commercial Conversion Depth（商业转化深度） is:

> **vertical-specific and capability-based（按垂直领域与能力决定）.**

The architecture may preserve these depths:

1. Level 1 — Discovery / Outbound（发现 / 外跳）
2. Level 2 — Intent / Lead Capture（意图 / 线索承接）
3. Level 3 — Booking / Transaction Enablement（预订 / 交易承载）
4. Level 4 — Marketplace / Intermediation（市场平台 / 交易中介）

## 2. Current boundary（当前边界）

The user confirms:

- Level 2–3（第二至第三级） should remain architecturally possible where a specific vertical genuinely justifies them;
- no current vertical is automatically forced into Level 2 or Level 3;
- Level 4 Marketplace（第四级市场平台） is **not** presumed and requires a separate future justification;
- one global statement such as “Ink & East（墨与东方） is a Marketplace（市场平台）” is not current truth.

## 3. Hard separations（硬分离）

Regardless of depth:
- advertising / Paid Amplification（广告 / 付费加热） does not buy Work Recognition（作品认可）;
- commercial conversion does not create source/truth authority（来源 / 真相权威）;
- commercial success does not create Contributor Qualification（贡献者资格）;
- organic / editorial / paid distribution provenance（自然 / 编辑 / 付费分发来源） remains distinguishable;
- actual merchant / service provider / transaction responsibility（实际商户 / 服务提供方 / 交易责任） must remain attributable.

## 4. Deferred implementation questions（暂缓实现问题）

Still undecided:
- which vertical reaches which level;
- exact lead forms;
- booking flows;
- payment model;
- refunds / cancellations;
- merchant responsibility;
- revenue share / transaction fees;
- provider qualification;
- Marketplace（市场平台） rules.
