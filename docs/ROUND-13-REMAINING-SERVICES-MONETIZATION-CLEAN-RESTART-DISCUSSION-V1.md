## 2. Fixed boundaries（固定边界）

The following are already controlled:

- Custom Reading（定制解读） = rejected / historical only（已淘汰 / 仅历史）;
- Custom Ebook Studio（定制电子书工作室） = rejected / historical only（已淘汰 / 仅历史）;
- Commission（约稿） = historical / superseded terminology（历史 / 已取代术语）;
- Membership（会员） = separate deferred subject（独立暂缓主题）, not to be silently used as the answer here;
- normal published platform content remains public（正常发布内容保持公开）;
- payment cannot buy authority / Recognition / Contributor Qualification / organic reach（付款不能购买权威 / 作品认可 / 贡献者资格 / 自然触达）;
- Paid / Sponsored Discovery（付费 / 赞助发现） is not currently authorized;
- Spatial Flow（空间流） relationship does not define Ink & East（墨与东方） monetization;
- optional joint commercial projects with Spatial Flow（空间流） may exist, but they remain project-specific.

## 3. The correct starting question（正确起点）

Do **not** begin by inventing pages, price tiers or service menus.

The first question is:

> **What does Ink & East（墨与东方） itself genuinely need to monetize, if anything, beyond future Membership（会员） and project-specific collaborations?**

Possible answers may include:
- no additional first-party paid product is currently necessary（目前不需要额外第一方收费产品）;
- one or more paid service/product families are genuinely needed（确实需要某些收费服务 / 产品族）;
- monetization should come mainly from organization/partner/project relationships（主要来自机构 / 合作方 / 项目关系）;
- another model（其他模式）.

No option is selected yet.

---

## 4. Need First, Container Second（先需求，后容器）

Any future Services / Monetization（服务 / 商业化） concept must first prove:
1. a real user / organization / platform need（真实用户 / 机构 / 平台需求）;
2. why payment is appropriate（为什么适合收费）;
3. why Ink & East（墨与东方） is the right party to provide it（为什么应由墨与东方提供）;
4. whether it conflicts with public knowledge/editorial integrity（是否与公共知识 / 编辑完整性冲突）;
5. only then should page / workflow / pricing / packaging（页面 / 流程 / 定价 / 包装） be designed.

No legacy service is revived by this restart.
