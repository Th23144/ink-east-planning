## 1. Governing Membership thesis（会员控制性主张）

Ink & East（墨与东方） Membership / Supporter Relationship（会员 / 支持者关系） is defined directionally as:

> **A voluntary, ongoing relationship that helps sustain Ink & East（墨与东方）, keeps the user closer to the platform's real work/process, enables deeper participation/belonging where genuine formats exist, and may gradually add mature platform utilities/conveniences as real value emerges.（一种自愿、持续的关系：帮助维持 Ink & East（墨与东方），让用户更接近平台真实工作的过程；在真实场景存在时形成更深参与与归属；并随着平台成熟逐步增加真正成立的工具与便利价值。）**

## 2. Four-layer value structure（四层价值结构）

### A — Support / Mission Relationship（支持 / 使命关系）
- support the continued operation of Ink & East（墨与东方）;
- support public-interest cultural / research / recovery work（支持公共价值文化 / 研究 / 寻回工作）;
- maintain transparency around what support sustains（持续知道支持推动了什么）.

### B — Process Visibility（过程可见性）
- project / research / recovery progress（项目 / 研究 / 寻回进展）;
- editorial / process updates（编辑 / 过程更新）;
- appropriate work-in-progress context（适当的进行中工作背景）;
- platform-building visibility（平台建设可见性）.

The user is not buying ownership of knowledge outcomes; the relationship is closer access to process/context where appropriate（用户不是购买知识成果本身，而是在适当范围内更接近过程与上下文）.

### C — Closer Participation / Belonging（更深参与 / 归属）
When real formats exist:
- selected feedback opportunities（部分反馈机会）;
- project briefings（项目简报）;
- salons / roundtables / events（沙龙 / 圆桌 / 活动）;
- selected research / product participation（部分研究 / 产品参与）.

Participation does not create Governance / Editorial / Recognition authority（治理 / 编辑 / 认可权）.

### D — Mature Utility / Convenience（成熟后的工具 / 便利价值）
Only when real demand/economics exist:
- Ad-free / Reduced Ads（无广告 / 减少广告）;
- advanced personal utility（高级个人工具）;
- advanced delivery / offline / storage / sync（高级投递 / 离线 / 存储 / 同步）;
- partner ecosystem benefits（合作生态权益）;
- other genuine maturity-dependent convenience（其他真实、依赖平台成熟度的便利价值）.

These are additions, not the core reason Membership（会员） exists.

## 3. Hard exclusions（硬边界）

Membership（会员） is not:
- a way to purchase Early Co-builder（早期共建者） history;
- a way to purchase Contributor Qualification（贡献者资格）;
- a path to Work Recognition（作品认可）;
- a Governance / Editorial Authority（治理 / 编辑权力） package;
- a paywall for ordinary public knowledge（正常公共知识付费墙）;
- a mechanism that deliberately degrades free users to manufacture value（故意削弱免费用户来制造会员价值）;
- a catch-all bucket for every paid product（所有付费产品的大杂烩）;
- a source of organic recommendation privilege（自然推荐特权）.

## 4. Relationship with Early Co-builder architecture（与早期共建者架构的关系）

Membership / Supporter Relationship（会员 / 支持者关系） remains a current/ongoing relationship axis.

Early Co-builder Relationship（早期共建者关系） remains a separate historical relationship axis.

They may overlap in one user, but neither creates the other.
