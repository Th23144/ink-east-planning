A reading on 「閒」 — the word a grandmother used.

From a reader in Suzhou · published in Issue 001 · Letters

「閒」 is one of those words English does not have a single equivalent for. It is not "leisure" — leisure has been bought from a clock. It is closer to availability without errand. Your grandmother used it to describe a state your week makes very hard to reach. We hold it as a future issue.

On Tao Yuanming, and quitting kindly.

From a reader in Edinburgh · published in Issue 001 · Letters

Tao Yuanming did not romanticize quitting; he bureaucratized it. The "Returning Home" rhapsody is a series of small administrative refusals — declining a banquet, walking past a clerk, naming a vegetable garden a desk. Read it as a slow letter of resignation, not a flight to the hills.

Read full reply in Issue 001 · Letters →
叄

On Zhuangzi's butterfly, kindly disagreeing with the translator.

From a reader in Berkeley · published in Issue 001 · Letters

The butterfly chapter is not a thought experiment about identity, despite a century of footnotes saying so. It is closer to a refusal of the question — the kind of refusal that is itself the answer. We pushed the translator's footnote down a level so the chapter could speak first.

WordPress contract

後 端 規 範

A station-level aggregator. Server-side rendered PHP template; no client-side AJAX in v1. Every block below is read-heavy, write-light — write surfaces all live upstream (article pages, Letters form). Cache aggressively, refresh on editorial actions only.

URL
/community Production path. The page is reachable from every site-nav (8th item) and every footer "Speak" column.
Render
Server-side PHP template, no AJAX in v1. Every section is rendered at request time from the cache layer. Pagination (when needed) is link-based.
§贰 Recent
GET /wp-json/wp/v2/comments?per_page=10&order=desc
filter: comment_approved='1' & meta hidden_by_editor != '1'
cache: WP transient · key ie_community_stream_recent · TTL 5–10 min · busted on new approved comment DOM shape verbatim from the #5a Reader Notes component spec — do not diverge the markup.
§叄 Editor's Choice
GET /wp-json/ie/v1/reader-notes?meta_key=editors_choice&value=1&per_page=4
cache: WP transient · key ie_community_choice · TTL 30 min · busted when editors toggle the meta Curated filter of §贰. Same comment row, re-rendered with .is-editors-choice.
§肆 Issue Discussion
GET /wp-json/wp/v2/posts?categories=issue&per_page=10
+ per-issue: SELECT COUNT(*) FROM wp_comments JOIN wp_posts ON post_ID=ID WHERE meta_key='ie_issue_id' AND meta_value=$id
cache: WP transient per issue · key ie_community_issue_$id · TTL 10 min Show only the count as a noun — no avatars, no last-poster, no reply density.
§伍 Open Letters
GET /wp-json/wp/v2/letter?status=published&per_page=3
excerpt = post excerpt (50–80 words), NOT post_content
cache: WP transient · key ie_community_letters · TTL 30 min Custom post type letter registered in #6. Anonymization happens at edit time on the WP admin side, not at render time.
Day-1 reality
Most sections will render empty at launch — the legacy 120+ articles are migrating, the new comment system is fresh, letters take a few weeks of editorial pause.
Each block above ships with an EMPTY VARIANT HTML comment that the server template substitutes when the result set is empty. The frame stays; the contents change. This is intentional. Empty here looks like a pause, not a broken page.
Permission
Read = open to all (guest / Reader / Patron). The page is purely a read-only aggregator. No tier-gated content. The visible shape does not change between guest and member.
Write surfaces
Not on this page. A new Reader Note is written upstream inside the article it belongs to (#reader-notes anchor on each article page). A new letter is written on the Letters form (./ink-east-letters-form-v1.html). This page hosts no composer, no textarea, no submission button.
A note on writing surfaces · 寫 入 之 口

This page does not host any composer; all writing happens upstream on article pages or the Letters form. If a future engineer is tempted to add a "post a note" textarea below the §贰 stream, the answer is: keep the door at the article. The aggregator is for listening.
